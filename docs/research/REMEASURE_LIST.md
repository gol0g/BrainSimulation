# C24 이후 재측정 목록 (2026-08-26)

**왜**: C24에서 체크포인트 로드가 학습 구조의 63.6%를 평균 상수로 파괴하고 있었음이 밝혀졌다
(시드 없음 → SPARSE 연결 매 런 무작위 → 개수 불일치 → 뭉갬). 로드 기반으로 잰 수치는
"학습된 뇌"가 아니라 **학습 경로가 초기값 상수로 치환된 뇌**를 잰 것이다.
따라서 아래는 전부 **재측정 전까지 인용 금지**.

## 재측정 프로토콜 (필수)
1. `brain_seeded_*` 체크포인트만 사용.
2. 로드 직후 `load_damage_audit.py`로 **파괴 0 확인** 후에만 측정.
3. **학습 전 뇌(무학습) 대조를 반드시 함께** 측정 — C24 이후 핵심 질문은
   "성능이 있느냐"가 아니라 **"학습이 기여하느냐"**로 바뀌었다.
4. 판정 기준을 **측정 전에** 선언(C22b에서 이 절차가 잘못된 결론을 실제로 막았다).
5. 반복 3회 이상, 오차막대와 함께 기록.
