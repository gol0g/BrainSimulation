# 개념 형성 궤적 (훈련량 vs 개념 점수)

evaluate_concepts.py --test all. 각 ep는 forager_brain 훈련량.

| 테스트 | 50ep | 120ep | 기준 | 판정 |
|---|---|---|---|---|
| 공간 기억 (rich zone) | 29.5% | 26.3% | >무작위14% | ✅ PASS |
| 먹이 변별 (selectivity) | 0.62 | 0.62 | (원본 400ep=0.67) | ↗ 완만 |
| call semantics (소리만) | 50.0% | 60.0% | >60% | ↗ 우연→상승 |

**핵심**: call semantics 50%(정확히 우연)→60% = 소리단서 개념이 **훈련으로 형성 중**
(구조결함 아님, 훈련량 문제). 공간 개념 이미 형성. 먹이변별 원본 0.67 향해 완만.
→ **개념 형성 방향 검증됨. 궤적 위. seq-wm의 "안됨"과 정반대.**

**다음**: 원본 수준(400ep)으로 이어훈련해 개념들 기준 넘는지 확정. 250ep 중간점 먼저.

## 250ep 정정 (2026-07-26) — 지난 "형성 중" 판단 틀림

| 테스트 | 50ep | 120ep | 250ep |
|---|---|---|---|
| 공간 기억 | 29.5% | 26.3% | 31.4% ✅ |
| 먹이 변별 | 0.62 | 0.62 | 0.64 |
| call semantics | 50% | 60% | **50%** |

**정정**: call 50→60→50 = 노이즈(n=30). 60%는 학습 아닌 우연 변동. "형성 중" 판단 철회.
**진짜 결론**: 훈련 5배(50→250ep)로도 실패 개념 안 움직임 = **훈련량 문제 아님.**
- 공간 개념 형성됨 ✅. 먹이변별 0.64(원본0.67로 아주 느림). call semantics 우연=실제 결함.
**다음**: 훈련 escalation 종료. call semantics(청각→행동) 직접 진단(diagnose_auditory).
교훈: 두 점 추세를 신호로 성급 선언(WM +0.42·ON==OFF와 동일 실수). n 작을 때 노이즈 경계.

## C2 회피강화 파일럿 반증 + base-rate 재해석 (2026-07-28)
회피 강화(d2_eta 0.0003→0.0006, dip 0.5→0.8) 50ep: selectivity 0.62 (baseline 0.64와 동일).
**회피학습 강화 가설 반증**(파일럿 스크린, 다중시드 안 감).

**base-rate 재해석(중요)**: 환경 good food 비율 0.6 → **무작위도 selectivity 0.60**.
브레인 0.62~0.64 = base-rate 겨우 2~4점 초과 = **거의 구별 못 함**("부분 성공" 아님).
훈련량(50→250 정체)·회피강화 둘 다 무효 → 학습파라미터 문제 아님.
원본 0.67(base+7)보다 낮음 = 재구현 격차 or 근본한계. **깊은 원인: good/bad 감각 표현.**
call semantics 실패(소리로 good/bad 구별X)와 같은 뿌리 가능성. → 공통 root 진단 다음.
