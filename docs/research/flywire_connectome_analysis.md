# FlyWire connectome 실측 분석 (2026-09-16)

> 데이터: `data/flywire/shiu_model/Connectivity_783.parquet` (MIT 라이선스, Shiu et al. Nature 2024)
> 원본: https://github.com/philshiu/Drosophila_brain_model / https://flywire.ai/
> 분석 스크립트: `scripts/flywire_stats.py`

## 왜 받았나
우리 뇌의 배선 파라미터(반사 가중치 25·시냅스 15,000, 학습경로 sparsity 0.08, 억제 −100~−400)는
**전부 내 추측**이다. "학습이 반사를 못 이긴다"가 **설계 실수인지 원리적 한계인지 구분할 근거가 없었다.**
FlyWire에는 실측값이 있다.

## 규모
- 뉴런 **138,639** / 연결(쌍) **15,091,983** / 시냅스 총합 **54,492,922**
- 우리 뇌는 28,323 뉴런 — 초파리의 약 1/5

## 핵심 실측치
| 항목 | 값 |
|---|---|
| 연결 밀도 | **7.85e-04** |
| 연결당 시냅스 | 중앙값 **2** / 평균 3.61 / p90 7 / p99 32 / p99.9 101 / max 2405 |
| 흥분:억제 (연결 수) | 60% : 40% |
| 억제/흥분 (시냅스 합) | **0.677** |
| 평균 강도 | 흥분 3.59 / 억제 3.65 (거의 동일) |
| 뉴런당 출력 연결수 | p50 80 / p90 205 / max 9,783 |
| 뉴런당 출력 시냅스합 | p50 229 / p90 788 / **p99 2,955** / max 99,871 |

## 우리 뇌와의 괴리 (→ H011)
1. **연결 밀도 100~190배 과밀** — 우리 sparsity 0.08~0.15 vs 실측 7.85e-04
2. **롱테일 부재** — 실측은 대부분 시냅스 1~2개에 극소수만 강함. 우리는 전부 균일 가중치
3. **반사 경로가 생물학적 상한 초과** — 우리 반사 1개 경로 15,000 시냅스 vs
   실제 뉴런 하나의 출력 시냅스합 p99 **2,955**. **5배 초과**
4. **억제 비율에 근거가 없었음** — 우리는 포화 해소만 보고 −100~−400을 튜닝. 실측 억제/흥분 = 0.677

## 시사점
관측된 포화 현상(d1 ~667 고정, direct 666 고정)은 **과밀 연결의 예상 증상**이다.
가중치(E069)·대역폭(E072)을 키워도 효과가 안 변한 것도 **균일 분포에서는 당연**하다.
→ **"학습이 반사를 못 이긴다"가 원리적 한계가 아니라 배선 설계 실수일 가능성** → H011로 등록.

## 한계 (정직)
- 초파리 뇌는 학습이 없다(Shiu 모델은 static). 배선 통계는 빌리되 **학습 구조는 우리가 만들어야 한다**
- 뉴런 수가 1/5이므로 밀도를 그대로 적용하면 연결이 과도하게 희박해질 수 있다. 스케일링 검토 필요
- 이 분석은 **전뇌 집계 통계**다. 영역별(MB/CX 등) 통계는 아직 안 봤다

## 버섯체(MB) 회로 실측 — 우리 KC 층이 죽어 있는 이유 (2026-09-16)
> 뉴런 분류는 Shiu repo에 없어 FlyWire Codex에서 별도 취득
> (`classification.csv.gz`, 유형은 `hemibrain_type`·`class` 컬럼).
> 분석: `scripts/flywire_mb.py`

### 실측 구성
| | 수 |
|---|---|
| KC (Kenyon Cell) | **5,177** |
| MBON (출력 뉴런) | **96** |
| DAN (PAM+PPL1 도파민) | **309** |

### 실측 연결
| 경로 | 연결 수 | 시냅스합 | 연결당 중앙값 / p99 | 억제 |
|---|---|---|---|---|
| **KC→MBON** | 51,111 | 219,572 | 3 / 18 | 0% |
| KC→KC | 284,506 | 366,907 | 1 / 4 | 0% |
| **DAN→KC** | **39,362** | 50,654 | 1 / 4 | 0% |
| DAN→MBON | 1,334 | 11,369 | 3 / 67 | 0% |
| MBON→MBON | 962 | 14,643 | 3 / 169 | **50%** |

### 수렴 구조
- **KC 1개 → MBON 10개** (중앙값, p90 13)
- **MBON 1개 ← KC 441개** (중앙값, p90 1,397)

### ★우리 뇌와의 결정적 차이
| 실측 | 우리 |
|---|---|
| KC 5,177 → MBON **96** | KC 2,000~4,000 → D1 **좌/우 2개** |
| KC 1개가 **MBON 10개**에 분산 | KC 1개가 D1 2개 |
| **DAN→KC 39,362 연결** (도파민이 KC에 직접) | **없음** — 도파민이 D1에만 |
| MBON→MBON **억제 50%** (상호 경쟁) | D1 간 경쟁 구조 없음 |

**가장 중요한 것: `DAN→KC`가 우리에게 없다.**
실제 초파리는 도파민 뉴런이 **KC에 직접 투사**해 KC→MBON 시냅스를 그 자리에서 변조한다.
**이것이 학습이 일어나는 지점**이다(문헌의 MB 가소성 = KC→MBON at DAN-innervated compartments).

우리 뇌는 도파민을 D1에만 주고 KC는 받지 않는다.
→ **C30에서 `kc_to_d1*`이 전부 "변화 없음"이었던 이유가 설명된다.
   가소성이 없는 게 아니라 학습 신호가 도달하지 않는다.**

### 출력 뉴런 수의 문제
실측은 **96개 MBON**이 KC 5,177개의 출력을 받는다(수렴비 약 54:1, MBON당 KC 441개).
우리는 **D1 좌/우 2개**가 KC 수천 개를 받는다 — 극단적 수렴이라 **변별이 평균화**된다.
관측된 D1 포화(~667 고정)와 정합한다.
