# E091: 보상 예측 오차가 정답을 붙잡게 하는가

- **등록일**: 2026-09-25
- **상태**: 등록됨
- **검증할 가설**: H020 — **기대 보상을 빼면(RPE) 정답에 도달한 뒤 갱신이 멎어 성능이 유지된다**
- **경쟁 가설**: H020-null(기준선을 넣어도 유지 안 됨), H020-partial(유지는 되나 성공률은 그대로)

## 배경 — E090이 지목한 결함
E090에서 학습의 핵심 결함이 **유지 실패**로 특정됐다(K31):
| 조건 | 성공률 | 파괴율 |
|---|---|---|
| eta 0.001, 400시행 | **25.0%** | 43.8% |
| eta 0.001, **1600시행** | **8.3%** | — |

**더 오래 훈련할수록 나빠진다.** 파괴율이 성공률보다 높고, 이미 완벽한 배선(w1·w2)도 부순다.

기전: 정답률 70%면 도파민이 70% 시행에서 +1, 30%에서 −1로 **계속 도착한다.**
성능이 좋아져도 멈출 조건이 없어 맞는 매핑도 계속 흔들린다.

**기대 보상을 빼면** 성능이 기대치에 수렴할 때 RPE → 0 이 되어 갱신이 멎는다.
Frémaux et al.의 요지이며, 외부 검토가 "전체 모델에 즉시 critic을 넣을 수는 없다"고 한 것을
**최소 회로에서는 넣어서 시험할 수 있다**.

> ⚠ E086 조정 중 `--baseline`을 시험해 "효과 없음"으로 봤으나, **그때는 시드가 안 잡혀
> 잡음이 51%p였다**(E089). 아무것도 안 보이는 것이 당연했다. 그 관측은 근거로 쓰지 않는다.

## 1. 조작
`--baseline`: **0.0(없음) / 0.02 / 0.1** — 기대 보상의 갱신률(러닝 평균).
도파민 = `da * (r − r̄)`, `r̄ ← r̄ + baseline*(r − r̄)`, r ∈ {+1, −1}.

- `--eta 0.001`(E090 최적), `--epsilon 0.6`
- **시행 수를 요인으로 넣는다**: 400 / 1600. 유지 실패는 긴 훈련에서만 드러난다.
- 배선 시드 0~4 × 난수열 100~107(8개) × baseline 3수준 × 시행 2수준 = **240런**
- 대조: 같은 배선의 `frozen`

**반복 근거**: E089 실측 표준편차 23.29%p, P18의 최소 8회.

## 2. 조작 검증  ★필수
1. **기준선이 실제로 도파민을 줄이는가**: baseline > 0에서 학습 후 `kc_out` |Δ|평균이
   baseline = 0 보다 **작아야** 한다. 같으면 조작 무효.
2. **포화 없음**: `max == w_max` 비율 **10% 미만**.
3. **배선 고정**: 같은 `--seed`에서 `n`이 조건과 무관하게 동일.
4. 두 조건 값이 소수점까지 같으면 조작 무효 의심.

## 4. 사전 판정 기준
**(a) 유지** — 주 판정. E090의 핵심 결함을 직접 겨냥한다:
- **지지**: baseline > 0 에서 **1600시행 성공률 ≥ 400시행 성공률 × 0.8**
  (긴 훈련이 성능을 깎지 않는다), 그리고 baseline = 0 에서는 그 비율이 **0.5 이하**
  (E090 재현: 25.0 → 8.3 = 0.33)
- **기각**: baseline > 0 에서도 1600/400 비율이 **0.5 이하**

**(b) 파괴율 하락**:
- **지지**: baseline > 0 의 파괴율이 baseline = 0(43.8%) 대비 **절반 이하**
- **기각**: 차이 5%p 이내

**(c) 성공률**: 유지가 개선돼도 성공률이 안 오를 수 있다. 함께 보고한다.
- baseline > 0 의 400시행 성공률이 baseline = 0(25.0%) 대비 어떤가.

## 5. 이 결과로 새로 알게 되는 것
- **(a)(b) 지지** → **정지 조건의 부재가 결함이었다.** 최소 회로의 첫 재현 가능한 성취가 되고
  회귀 검증으로 남긴다. 그다음은 전체 모델에 같은 기전이 없다는 것을 확인하고 넣는 것이다
  (`forager_brain.py`의 `release_dopamine`에는 기대 보상 항이 없다).
- **(a) 기각** → RPE로는 유지가 안 된다. 가중치 자체를 붙잡는 기전(공고화·감쇠 정지·
  시냅스별 학습률 감소)이 필요하다는 뜻이며, 그쪽으로 옮긴다.
- **(a) 지지, (c) 하락** → 유지와 탐색이 상충한다. RPE가 갱신을 너무 일찍 멈춰
  정답을 찾기 전에 학습이 끝나는 것이다. 기준선 갱신률의 용량-반응이 다음 질문이 된다.

## 6. 이 대조가 **식별하지 못하는 것**
- **조건 간 차이 전부**: `--baseline`과 `--trials` 둘. 배선·난수열·eta·회로 전부 동일.
  조작검증 3이 연결 개수로 배선 동일성을 확인한다.
- **의도한 차이**: 기대 보상 차감의 유무·강도, 그리고 훈련 길이.
- **지표 상쇄 검토**: 지표가 성공률·유지율(빈도)이고 관심 요인은 baseline이다. 뺄셈 양변에 안 들어간다.

### 이 결과로도 배제 못 하는 설명
1. **기준선이 전역 스칼라다**: 자극별·상태별 기대 보상이 아니라 하나의 러닝 평균이다.
   실제 critic은 상태 의존적이다. 여기서 안 되어도 **상태 의존 critic이 안 된다는 뜻은 아니다**.
2. **유지 판정이 두 시행 길이의 비교다**: 400과 1600 사이의 형태(언제 무너지는가)는 안 보인다.
3. **배선 기준선이 삼분된다**: 여지 시드가 3개뿐이고 w0은 E089에서 8/8 실패했다. 표본이 작다.
4. **과제 1종**: 2지선다에서 정답에 도달하면 보상률이 ~100%로 포화한다.
   보상률이 중간에 머무는 과제에서는 RPE가 다르게 작동할 수 있다.

## ★ 전제가 무너졌다 — K31 철회
**대조 조건(baseline=0)의 유지율이 0.83이다.** E090에서 관측한 0.33이 재현되지 않는다.

| | 400시행 | 1600시행 | 비 |
|---|---|---|---|
| E090 | 25.0% (6/24) | **8.3% (1/12)** | 0.33 |
| E091 | 25.0% (6/24) | **20.8% (5/24)** | 0.83 |

400시행은 **25.0%로 정확히 일치**한다. 차이는 장기 조건뿐이고,
E090은 **12런**(1/12), E091은 **24런**(5/24)이다. **1/12과 5/24는 구분되지 않는다.**

→ **K31("학습이 정답을 찾아도 붙잡지 못한다")은 표본 12개의 우연이었다.**
→ **이 실험 전체가 존재하지 않는 문제를 고치려던 것이다.**

### 새로 알게 된 것
1. **K31 철회.** E090의 보조 조건은 12런이었고, 그 크기에서 8.3%와 20.8%는 구분되지 않는다.
   **규약 P18을 만들어놓고 보조 조건에는 적용하지 않았다** — 본 조건은 조건당 8회를 지켰는데
   보조는 4회(3시드×4난수열)였다.
2. **전역 스칼라 RPE는 효과가 없다.** 다만 6번에 적은 대로 이는 **상태 의존 critic**과 다르다.
3. **학습의 복권성은 그대로 남아 있다**(K29·K30). 성공률 20~29%, 파괴율 31~50%.
   여전히 **파괴가 성공보다 빈번**하다.
4. **E090의 (a)(c) 판정은 유효하다** — eta 0.02 → 0.001로 성공률 3배는 각 24런이었다.
   무너진 것은 12런짜리 보조 조건뿐이다.
