# E087: 학습이 보상 방향으로 가는가 — 부호 진단

- **등록일**: 2026-09-25
- **상태**: 등록됨
- **검증할 가설**: H017 — **R-STDP가 보상받은 동시활동을 올바른 방향으로 강화한다**
- **경쟁 가설**: H017-null(강화는 하는데 방향이 보상과 무관), H017-inv(부호가 반대)

## 배경 — K27이 남긴 질문
E086에서 학습이 배선을 **덮어쓰지만 방향을 보상에 맞추지 못한다**는 것이 확인됐다:
s0은 배선 0% → 학습 **100%**(반대 배선을 뒤집음), s1은 배선 100% → 학습 **49%**(완벽한 배선을 파괴).
같은 크기로 반대 방향이다. **힘은 충분한데 방향 제어가 안 된다.**

E086은 탐색·선택 피드백·신용할당이 섞여 있어 어느 단계가 방향을 잃는지 못 가른다.
E087은 **그 셋을 전부 제거**한다.

## 1. 조작 — `--mode supervised`
- 탐색 없음: 매 시행 **정답 행동을 강제**한다(`act = RULE[stim]`).
- 선택 피드백 없음: 행동이 네트워크 상태와 무관하게 정해지므로 폭주 루프가 생기지 않는다.
- 신용할당 모호성 없음: 강제한 행동이 그대로 출력에 주입되어 자격흔적에 남는다.
- **항상 보상**한다(정답만 하므로).

남는 질문은 하나다: **보상 + 동시활동이 올바른 시냅스를 강화하는가.**

대조: `frozen`(학습률 0) — 같은 시드, 같은 구조.

## 2. 조작 검증  ★필수
1. **가중치가 실제로 변하는가**: supervised에서 `kc_out` 변화율 > 0, frozen에서 = 0.
2. **KC 분리 유지**: A전용·B전용 KC 집합이 각각 존재한다(자카드 ≤ 30%).
3. **시드 고정**: `m.seed` 설정 확인 — 훅 `lab_seed_guard.sh`가 누락을 차단한다.
4. 두 조건 값이 소수점까지 같으면 조작 무효 의심.

## 3. 불변식 확인
- [x] **INV-A1 GeNN 시드 고정** — `m.seed = 12345 + seed`. **C-5 사고 후 훅으로 강제됨**
- [x] INV-A2 random/np.random 시드 고정
- [~] INV-A3/A4/A5 — 해당 없음 (사유: 전체 모델의 D1/direct 배선이 이 회로에 없다)
- [~] INV-A6 — 해당 없음 (사유: 평가는 탐색·학습 없는 별도 단계이며 시행 사이 무자극 600스텝)
- [~] INV-B1 변조폭 — 해당 없음 (사유: 지표가 **가중치 구조**다. 행동 지표가 아니다)
- [x] INV-B2 무학습 대조 — `frozen`
- [x] INV-B3 같은 시드 짝짓기
- [~] INV-B4/B5 — 해당 없음 (사유: 행동 측정을 쓰지 않는다)

## 4. 사전 판정 기준
**지표는 정답률이 아니라 가중치 구조다.** A에만 반응하는 KC의 `out_L` 가중치가 `out_R`보다 큰가.

**(a) 방향성** — 주 판정:
- **지지**: `A전용 KC → out_L 평균 − out_R 평균 > 0` **그리고** `B전용 KC → out_R − out_L > 0`,
  **5시드 중 4 이상에서 양쪽 다**
- **기각**: 5시드 중 2 이하
- **H017-inv**: 5시드 중 4 이상에서 **양쪽 다 반대** → 부호가 뒤집혀 있다

**(b) 크기** — (a) 통과 시:
- 차이의 평균이 초기 가중치(0.5)의 **20% 이상**이어야 행동에 영향을 줄 수 있다.

**(c) 행동 이전** — (a)(b) 통과 시:
- supervised로 학습한 뒤 평가(탐색 없음) 정답률이 frozen 대비 **+15%p 이상**, 4/5 시드.
- 이것이 기각되면 **가중치는 맞는데 읽어내지 못하는 것**이고, 병목이 출력 단계로 특정된다.

## 5. 이 결과로 새로 알게 되는 것
- **(a) 기각 또는 inv** → **학습 규칙 자체가 방향을 못 잡는다.** 신용할당·탐색·구조를 아무리
  손봐도 소용없다. E069부터 17건이 찾던 병목은 여기였던 것이 된다. `rstdp_model.py`의
  갱신식·자격흔적 부호를 직접 검토한다.
- **(a)(b) 지지, (c) 기각** → 가중치는 올바르게 학습되는데 **행동으로 안 나온다**.
  병목이 출력 읽기(WTA·경쟁·임계)로 특정된다. E086에서 평가값이 0/50/100으로 삼분된 것과 정합.
- **(a)(b)(c) 전부 지지** → 지도 조건에서는 학습이 완전히 작동한다.
  그러면 문제는 **탐색으로 정답을 찾아내는 과정**이고, 그것이 다음 실험이 된다.

## 6. 이 대조가 **식별하지 못하는 것**
- **두 조건의 차이 전부**: `--mode`(supervised / frozen) 하나. frozen은 학습률만 0이고 배선은 같다.
  시드·회로·파라미터 전부 동일.
- **의도한 차이**: 학습의 유무.
- **지표 상쇄 검토**: 지표는 가중치 구조의 절대 차이이고 관심 요인은 모드다. 뺄셈 양변에 안 들어간다.

### 이 결과로도 배제 못 하는 설명
1. **지도 학습은 실제 과제가 아니다**: 정답을 강제하므로 탐색으로 답을 찾는 능력은 전혀 시험하지 않는다.
   여기서 되어도 자율 학습이 된다는 뜻이 **아니다**.
2. **A전용/B전용 KC만 본다**: 양쪽에 반응하는 KC(겹침 ~11%)는 분석에서 빠진다.
   그쪽에서 반대 방향으로 학습하고 있어도 안 잡힌다.
3. **가중치 평균만 본다**: 소수의 강한 시냅스가 다수의 약한 시냅스를 상쇄하는 구조는 평균에 안 나온다.
4. **과제 1개·회로 1개**: 이 회로에서의 결과이며 전체 모델로의 이전은 별도 문제다.

### 새로 알게 된 것
