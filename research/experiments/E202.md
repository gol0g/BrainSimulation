## 1. 조작 (Manipulation)
- **측정(행동 조작 없음)**: E200 본실험과 같은 커맨드(경쟁형 규칙 `--kc-motor-hard --kc-motor-comp`·η 2.4·도파민 기준선 `--da-baseline`·C2·기저값 −4900·catctx 3,000시행, 뇌 10~14·같은 시드)에 읽기 전용 계측 `--trace-dg traces/E202/dg_b{B}.npz` 만 더한다 — 매 시행 도파민 방출 직전 KC→motor 4경로 g·e, 보상 창 뒤 도파민 0 직후(KC 별 정규화 전) g 를 당겨(장치 값 불변) KC 별 경로 평균 Δg 의 교차 − 같은 쪽 차 x 를 (실행 motor 가 자극 쪽 S / 반대 C) × (보상 + / 무보상 −) 범주로 누적한다. 학습만(이식 평가 없음 — 학습이 E200 과 같은지는 조작검증 (2) 로 확인).
- **분해**(abcd C절, 결과 전 고정): 선택성 약한 반응 KC(SXI 크기 < 0.1) 무리의 균형 평균(교차 KC 평균 + 같은 쪽 KC 평균)/2 로 범주 c 의 X_c = Σ_{t∈c} x, W_c = Σ_{t∈c} DA, m_c = X_c/W_c; 짝 r ∈ {+, −} 마다 μ_r = (m_Cr − m_Sr)/2, d_r = (m_Sr + m_Cr)/2 → D_obs = Σ X_c = D_freq + D_mag, D_freq = Σ μ_r·(W_Cr − W_Sr)(같은 크기에서 도파민 합의 비대칭), D_mag = Σ d_r·(W_Sr + W_Cr)(같은 도파민에서 흔적 크기 비대칭).
  - **정의 다듬음(2026-10-17, 결과 전)**: abcd 는 μ = (|m_S| + |m_C|)/2 로 적었다. 기대 부호(m_S ≤ 0 ≤ m_C)에서는 같은 값이고, 부호가 어긋나도 항등식 D_obs = D_freq + D_mag 가 정확하도록 부호 있는 μ = (m_C − m_S)/2 로 둔다(판정기·독립 대조 모두).
