- **상태**: 등록됨

- **경쟁 가설**: H039-d1(D1·교차 경로 주도), H039-map(매핑 차이 D 주도)

> 출처: E110(반사 강화 +0.27, 10/10) → E111(흔적 부호 정상, 사후 분석: 공통 상승 97%). 판별 방법은 E111 사후 분석 워크플로가 제안한 부분 이식 분해.

## 1. 조작 (Manipulation)
**1단계(학습·저장)**: E110 조건(eta 0.15, `--reward-stim none`) 그대로 + `--save-weights logs/E112/w_b{B}.npz`, 뇌 0~4 (5런).
**2단계(평가만)**: `--decomp-weights w_b{B}.npz --decomp-mode M --episodes 0`, 같은 cfg. 이식 평가와 같은 경로(`TE.build_from_cfg` 새 뇌 + 워밍업 → push → verify → evaluate).
| 모드 | 이식하는 것 |
|---|---|
| none | 아무것도(학습 전 뇌) |
| all | 저장된 전부(= E110 사후) |
| kc_only | KC→motor 4개만 |
| d1_only | food→D1 (교차 포함)만 |
| kc_shuffle | 전부, 단 KC→motor 각 그룹 안에서 시냅스 순서 섞음(그룹 평균·분포 보존, 구조 파괴, 시드 777) |
| kc_uniform | 전부, 단 KC→motor 각 그룹을 그룹 평균으로(공통 상승 + 매핑 차이 D 보존) |
| kc_cm | 전부, 단 KC→motor 네 그룹을 전체 평균 하나로(공통 상승만 보존) |
7모드 × 5뇌 = 35 평가 런. 러너 `scripts/e112_main.sh`, 판정 `scripts/judge_e112.py`.

## 2. 조작 검증 (Manipulation check)  ★필수
- **재현**: all = 1단계 로그의 [사후] 변조폭, none = [사전] 변조폭 — **소수점 4자리 동일**(5/5). 다르면 분해 경로가 이식 경로와 다름 → 판정 무효.
- **1단계 = E110**: 1단계 사후 변조폭이 E110 eta0.15 학습 같은 뇌와 4자리 동일(저장만 추가).
- **push 검증**: 각 런 verify 통과(예외 없음), pushed 수가 모드 정의와 일치(none 0, kc_only 4, d1_only = D1 경로 수, 나머지 전부).
- **변형이 들었는가**: kc_shuffle·kc_uniform·kc_cm 이 all과 소수점까지 같으면 그 변형은 무효 의심(보고).

## 4. 사전 판정 기준  ★필수 (실행 전에 못박는다)
뇌별 총효과 T = mod(all) − mod(none). |T| < 0.05 인 뇌는 제외(수 보고).
분율: KC = (mod(kc_only) − mod(none))/T, D1 = (mod(d1_only) − mod(none))/T.
KC 효과 E_kc = mod(all) − mod(d1_only). E_kc 대비 분율: 구조 S = (mod(all) − mod(kc_shuffle))/E_kc, 매핑 D = (mod(kc_uniform) − mod(kc_cm))/E_kc, 공통 CM = (mod(kc_cm) − mod(d1_only))/E_kc.
- **(a) 경로**: KC ≥ 0.7 인 뇌 ≥4/5 → **KC 주도** / D1 ≥ 0.7 인 뇌 ≥4/5 → **H039-d1** / 그 외 "혼합"(비선형 상호작용 가능 — KC + D1 ≠ 1 보고).
- **(b) KC 안의 성분**((a) KC 주도일 때): S·D·CM 중 **≥0.5 인 성분**이 뇌 ≥4/5에서 같으면 그 성분이 주 출처. D가 주 출처 → **H039-map**, S 또는 CM → **H039 지지**. 아무 것도 ≥0.5 아님 → 보류.
- **예산**: 5 학습 + 35 평가.
