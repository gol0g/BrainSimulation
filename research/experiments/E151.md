## 4. 사전 판정 기준  ★필수 (실행 전에 못박는다)
`logs/E151/criteria_fixed.txt` 그대로. eA1 = base(A) − base(무학습), eA = base(AB) − base(무학습), rA = eA/eA1, eB = bad(AB) − bad(무학습), T = (eA − eA1)/eB. 1e-4 정수.
- 조작검증 실패 → 둘 다 보류. P1'·P2' 실패 → 둘 다 보류(학습 크기 미회복).
- **판정 1(기전)**: 뇌별 eB ≥ +0.15 이고 T ≤ 0.8 → 전이 감소, T ≥ 1.0 → 기본 수준 전이. 전이 감소 ≥4/5 → **H074**, 기본 수준 전이 ≥4/5 → **H074-mag**, 그 밖 보류. 비교값: 기본 E148 T 1.18~1.31, 차단 E150 0.41~0.73.
- **판정 2(능력)**: rA ≥ 0.5 ≥4/5 → 전체 강도 유지, rA < 0.5 ≥4/5 → 전체 강도 간섭, 그 밖 보류.
- 반복 수: 뇌 5(E150 과 같은 뇌). 대조: 같은 차단·같은 η* 의 A단독, 무학습; 기본 상태 E148 T(부지표 비교값).
- **교란(사전 명시)**: 조밀 KC(E149)·피질 입력 상실 — 이 실험으로 안 갈림. 큰 eta 의 연성 상한·절단 영역(η* 는 가장 작은 후보). 기본 상태 T 는 eta 0.15·다른 날.
- **사전 노출**: E150(eta 0.15) 결과는 알려져 있다. 보정은 표본 밖 뇌 15 의 eA1·eB 만 본다(AB base 평가 안 함 — 유지 몫 비노출). 기준은 보정 전에 고정.
- **결과별 다음 결정**: 분기 상한 1 — 결과와 무관하게 종료. H074 + 유지 → 차단 설계에서 앞 능력(K80 일반화·K81 반전) 회귀 검사. H074 + 간섭 → 전이는 줄지만 전체 강도에서 절반 못 지킴 — 남은 공유(조밀 KC)가 문제: KC 성김 회복 또는 경험 형성 표현. H074-mag → E150 유지는 약한 학습 탓: 간섭 원인 미해결(공통 입력 차단은 해결책 아님) — 경험 형성 표현 또는 출력 쪽. 보류 → 미해결 기록.
- **예산**: 보정 약 1~1.7시간(뇌 15) + 본실험 약 3시간.

## 5. 이 결과로 새로 알게 되는 것  ★필수
E150 의 '공통 입력 차단 → 유지'가 표현 쪽(같은 학습 크기에서도 과제 B 가 과제 A 자극으로 덜 번짐)인지, 차단이 학습을 약하게 만든 부산물인지. 그리고 차단 설계 전체 모델이 전체 강도에서 상충 연합을 함께 담는지(최소 회로 K51 의 보존 여부) — 전체 모델의 다음 능력(전이)으로 갈 기준선을 정한다.
