## 4. 사전 판정 기준  ★필수 (실행 전에 못박는다)
`logs/E205/criteria_fixed.txt` 그대로(고정 시각은 파일에 date 로). 1e-4 정수(로그 4자리). 칸·효과는 학습 − 무학습(none, 같은 뇌·같은 평가 경로).
- **L4(GW·UW 뇌마다 — E204 와 같은 범주)**: 칸 a = 규칙 방향(learn − none); 맥락 의존 범주 = 네 칸 a_train ≥ 1000 + 네 칸 a_new ≥ 500 이면서 2·a_new ≥ a_train; 사례 한정 = 네 칸 획득·일반화 실패; 부분 = 획득 2~3 칸; 실패 = 획득 ≤ 1 칸. m = 가장 약한 칸 a_train.
  - **L4 판정**: GW 맥락 의존 범주 ≥ 4/5 이고 게이팅 효과(m_GW − m_UW ≥ 500 인 뇌 ≥ 4/5) → **확증**; GW ≥ 4/5 이나 게이팅 효과 < 4/5 → **체계 확증(게이팅 효과 미확증)**; GW < 4/5 → **미확증**.
- **앞 능력(뇌마다 — 원 실험 정의 그대로; e = m(학습) − m(무학습), A 교차(−)·B 같은 쪽(+)·C 같은 쪽(+)·D 교차(−))**:
  - (가) **범주 규칙 R**(E185 확증 정의): 개념 수준 = e_A,train ≤ −1000·e_B,train ≥ +1000 이면서 e_A,new ≤ −500·e_B,new ≥ +500·2·e_A,new ≤ e_A,train·2·e_B,new ≥ e_B,train. 사례 한정 = 획득·일반화 아님, 한 범주만 = A 만 또는 B 만 획득, 획득 실패 = 둘 다 아님. **보존** = 개념 수준 ≥ 4/5, **잃음** = 획득 실패 ≥ 4/5, 그 밖 **부분**.
  - (나) **반전 V**(E188 정의, 반전 전 기준 = 같은 뇌 R): 반전 획득 = e'_A,train ≥ +1000·e'_B,train ≤ −1000, 반전 일반화 = e'_A,new ≥ +500·e'_B,new ≤ −500·2·e'_A,new ≥ e'_A,train·2·e'_B,new ≤ e'_B,train; 부분 반전 = 획득 아님·Δ_A,train ≥ +1000·Δ_B,train ≤ −1000(Δ = e' − e_R); 고착 = |Δ_A,train| < 500·|Δ_B,train| < 500. **보존** = 반전 성공(획득·일반화) ≥ 4/5, **잃음** = 고착 ≥ 4/5, 그 밖 **부분**.
  - (다) **유지 P**(E190 정의): 첫 쌍 기준 = e_R,A,train ≤ −1000·e_R,B,train ≥ +1000; 둘째 쌍 획득(전제) = e_P,C,train ≥ +1000·e_P,D,train ≤ −1000; 유지 = 기준·전제 충족 이면서 2·e_P,A,train ≤ e_R,A,train·2·e_P,B,train ≥ e_R,B,train(유지 몫 r ≥ 0.5 두 범주); 간섭 = 기준·전제 충족·유지 아님. 기준 < 4/5 → **보류(기준 미달)**, 전제 < 4/5 → **보류(전제 미달)**, **보존** = 유지 ≥ 4/5, **잃음** = 간섭 ≥ 4/5, 그 밖 **부분**.

(3) 잃는 곳은 상충 학습 아래 유지 하나이고, 옛 체계(4~39% 남음)보다 더 세게 잃는다 — 첫 쌍 규칙이 공유 단위로 둘째 쌍에 이미 번져 있고(R 의 C·D 전이) 둘째 쌍은 그 정반대를 배워야 하므로, 다시 쓰기가 빠른 규칙(반전 크기도 옛 체계보다 큼)이 공유 단위 가중치를 덮어쓴다는 설명과 맞다 — 공유 표현의 안정성–가소성 맞교환(K120·K122 의 U 쪽)과 같은 방향.
  - **미해결**: (1) 유지 실패의 기전은 직접 재지 않았다 — 공유 단위 덮어쓰기는 R 의 C·D 전이와 반전 크기에서 끌어낸 해석이다(KC 별 가중치 변화는 traces/E205 로 사후 기술 가능 — 판정 밖). (2) 앞 능력은 맥락 X 고정·과제마다 새 뇌에서 따로 잰 것 — 순차 평생 학습(L4 뒤 같은 가중치로 다음 과제)이 아니며, 맥락 없는 상태(무학습 motor 평균 0.4316 — 경로 검사)의 앞 능력은 범위 밖. (3) 게이팅은 설계 구조(학습된 게이팅 아님)이고 T_G 는 뇌 15·세계 18300 보정값 — 새 뇌·세계 동작점(0.577~0.608)은 보고만 했다. (4) 학습은 호스트 보상 창 흔적 동결(K99)·경쟁형 규칙(호스트 정규화)·도파민 기준선 위 — 국소 규칙만의 학습이 아니다.
