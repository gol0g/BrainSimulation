# E089: 학습 결과의 불안정성 크기

- **등록일**: 2026-09-25
- **검증할 가설**: M002 (측정 가설) — **같은 배선·같은 조건에서 시행 난수열만 바꿔도 학습 결과가 크게 갈린다**
- **경쟁 가설**: M002-null(난수열의 영향은 작고, E087↔E088 차이는 다른 이유)
- **상태**: 등록됨

## 배경 — E088이 남긴 문제
`supervised(정답 50%)`와 `learn(eps=1.0)`은 **행동 분포가 동일**한데 5시드 중 2개에서
결과가 뒤집혔다(s1 100↔49, s3 100↔47). 다른 것은 난수열뿐이었다.

그렇다면 **E086~E088의 모든 판정이 의심스럽다.** 조작의 효과를 재기 전에
**아무것도 바꾸지 않았을 때의 변동 폭**을 먼저 알아야 한다(규약 P16).

전체 모델에서 이미 같은 일을 겪었다: 측정 바닥이 0.045인데 효과 0.008을 쫓고 있었다(K22).
최소 회로에서는 결정론이 확보돼 **런-간** 잡음은 0인데, **난수열-간** 변동은 아직 안 쟀다.

## 1. 조작
`--trial-seed`를 신설했다. **배선(`--seed`)은 고정**하고 **시행 난수열만** 바꾼다.
- 배선 시드 0~4 (E086~E088과 동일)
- 각 배선마다 시행 난수열 100~107 (8개)
- `--mode learn --epsilon 0.6` (E088에서 효과가 가장 컸던 조건)
- 대조: 같은 배선의 `frozen` (시행 난수열과 무관 — 학습이 없으므로)
= **45런** (learn 5×8 + frozen 5)

## 2. 조작 검증  ★필수
1. **배선이 실제로 고정되는가**: 같은 `--seed`, 다른 `--trial-seed`에서 `kc_out` 연결 개수 `n`이 같아야 한다.
2. **시행 난수열이 실제로 달라지는가**: 보상률(`reward=`)이 난수열마다 달라야 한다.
3. **포화 없음**: `max == w_max` 비율 10% 미만.
4. 두 조건 값이 소수점까지 같으면 조작 무효 의심.

## 3. 불변식 확인
- [x] **INV-A1 GeNN 시드 고정** — 훅 `lab_seed_guard.sh`가 강제
- [x] INV-A2 random/np.random 시드 고정
- [~] INV-A3/A4/A5 — 해당 없음 (사유: 전체 모델 배선이 이 회로에 없다)
- [~] INV-A6 — 해당 없음 (사유: 평가가 별도 단계, 시행 사이 무자극 600스텝)
- [x] INV-B1 지표 — 평가 정답률(2지선다, ill-posed 아님)
- [x] INV-B2 무학습 대조 — `frozen`
- [x] INV-B3 같은 배선 시드로 짝짓기
- [~] INV-B4/B5 — 해당 없음 (사유: 이력 의존 행동 측정을 쓰지 않는다)

## 4. 사전 판정 기준
**(a) 불안정성 크기** — 주 판정:
- 각 배선 시드에서 8개 난수열의 평가 정답률 **최대−최소**를 구한다.
- **M002 지지**: 그 폭의 **중앙값이 15%p 이상** → E086~E088의 판정 기준(+15%p)이
  **잡음보다 작거나 같다** = 그 판정들을 신뢰할 수 없다.
- **M002 기각**: 중앙값 **5%p 이내** → 난수열은 원인이 아니며 E087↔E088 차이는 다른 이유다.

**(b) 판정 무효 범위** — (a) 지지 시:
- 불안정 폭이 15%p를 넘는 배선 시드의 수를 세고, 그 시드가 포함된 과거 판정을 **명시적으로 무효화**한다.

**(c) 필요 반복 수** — (a) 지지 시:
- 관측된 표준편차로부터, +15%p 효과를 검출하는 데 필요한 난수열 반복 수를 계산해
  **앞으로의 실험 설계 기준**으로 삼는다(규약 P11·P12).

## 5. 이 결과로 새로 알게 되는 것
- **(a) 지지** → E086·E087·E088의 판정이 전부 **잡음 위에서 내려졌다.** 세 실험을 무효화하고,
  난수열 반복을 포함한 설계로 다시 짠다. 이것이 최소 회로의 **첫 신뢰할 수 있는 측정 기준**이 된다.
- **(a) 기각** → 난수열은 원인이 아니다. 그러면 E087↔E088의 s1·s3 차이를 만든 **다른 요인**을
  찾아야 한다(두 모드의 코드 경로 차이를 직접 비교).
- 어느 쪽이든 **다음 실험의 반복 수가 정해진다.** 지금은 근거 없이 5시드를 쓰고 있다.

## 6. 이 대조가 **식별하지 못하는 것**
- **조건 간 차이 전부**: `--trial-seed` 하나. 배선·회로·파라미터 전부 동일하며
  조작검증 1이 연결 개수로 확인한다.
- **의도한 차이**: 시행 난수열(행동 선택·자극 순서).
- **지표 상쇄 검토**: 지표는 평가 정답률의 **분산**이다. 관심 요인이 뺄셈 양변에 들어가지 않는다.

### 이 결과로도 배제 못 하는 설명
1. **난수열이 두 가지를 동시에 바꾼다**: 행동 선택과 자극 순서가 같은 `rng`를 쓴다.
   둘 중 어느 쪽이 불안정성의 원인인지는 **구분하지 못한다**.
2. **epsilon 0.6 하나만 본다**: 다른 탐색 강도에서 불안정성이 다를 수 있다.
3. **배선 기준선이 삼분된다**(0/~50/100): 천장·바닥에 걸린 시드는 변동 폭이 인위적으로 작게 나온다.
   s1·s2(frozen 100%)가 특히 그렇다.
4. **평가 자체의 변동은 이미 0**임이 확인됐다(결정론). 여기서 재는 것은 **학습 과정**의 변동이다.

## ★ E086·E087·E088 판정 전부 무효
세 실험 모두 **조건당 1런**으로 **+15%p** 기준을 썼다. 잡음 바닥이 **51%p**다.
- **E086** (a) 기각 → 무효. "1/5 시드만 학습"은 복권 결과였다.
- **E087** (a) 보류 / (c) 기각 → 무효. 가중치 구조 결과만 남는다(행동과 별개 지표).
- **E088** (a) 미달 / (b) 위반 / (c) 위반 → 무효. epsilon 용량-반응도 잡음이었다.

E088에서 이미 "E087 해석 철회"를 했지만 그때는 **크기를 몰랐다.** 이제 안다.

## 이 데이터가 주는 더 유용한 그림 — 학습은 복권이다
평가값이 **양자화**돼 있다: 배선 기준선에 머물거나 **100%로 점프**하거나. 중간이 없다.

| 구분 | 런 수 | 100% 도달 | 비율 |
|---|---|---|---|
| 배선이 불완전(w0·w3·w4) | 24 | 2 | **8%** |
| 배선이 이미 완벽(w1·w2) | 16 | (5번 **파괴**) | **31% 파괴** |

**학습은 8% 확률로 정답을 찾고, 31% 확률로 있던 답을 부순다.**
"학습이 안 된다"가 아니라 **성공/실패가 이산적이고 드물다**는 것이다.
w0은 8런 모두 100%에 못 갔다(44~56) — 배선이 완전히 반대인 경우는 한 번도 못 뒤집었다.

### 새로 알게 된 것
1. **최소 회로의 잡음 바닥은 51%p다.** 이보다 작은 효과는 조건당 19회 이상 반복해야 보인다.
   앞으로 모든 최소 회로 실험은 **난수열 반복을 설계에 포함**한다(규약 P18).
2. **학습 결과는 이산적이다.** 연속적으로 좋아지는 것이 아니라 **정답을 찾거나 못 찾거나**다.
   따라서 지표를 평균 정답률이 아니라 **성공률(100% 도달 비율)**로 잡는 것이 맞다.
3. **파괴가 성공보다 빈번하다**(31% vs 8%). 학습이 순이득이 아니다.
4. **E069~E088의 19건 중 행동 기반 판정은 대부분 잡음 위에 있었다.**
   전체 모델은 K22(이력 의존 0.045 vs 효과 0.008), 최소 회로는 이것(51%p vs 15%p).
