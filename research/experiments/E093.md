# E093: 가중치 획득률을 무엇이 정하는가

- **등록일**: 2026-09-25
- **상태**: 등록됨
- **검증할 가설**: H022 — **자격흔적 시간폭(tau_e)과 행동 주입 강도가 가중치 획득률을 정한다**
- **경쟁 가설**: H022-null(둘 다 무관), H022-wiring(배선이 지배하며 파라미터는 무의미)

## 배경 — E092가 병목을 가중치 획득으로 특정했다
| 단계 | 통과율 |
|---|---|
| 가중치 획득(양쪽 방향 정답) | **9/24 = 37.5%** |
| 읽어내기(가중치 정답 → 평가 100%) | 6/9 = 67% |

가중치가 틀린 15런 중 평가 100%는 **0건**이다. 읽어내기는 병목이 아니다.
또한 **w4는 8/8 실패**이고 A전용 차이가 8번 모두 음수 — 배선 의존성이 크다(K33).

## 왜 이 두 파라미터인가
학습이 일어나는 시퀀스: 자극 50스텝 → 행동 주입 15스텝 → 도파민 20스텝.
- **tau_e(200)**: 동시활동에서 도파민까지 약 35~65스텝 걸린다. 흔적이 너무 빨리 죽으면
  신용이 안 남고, 너무 길면 **앞 시행의 흔적이 섞인다**.
- **act_drive(6.0)**: 고른 행동을 출력에 주입하는 세기. 너무 약하면 흔적에 안 남고,
  너무 강하면 출력이 포화해 **자극별 차이를 덮는다**(E086에서 출력이 30→300으로 폭주한 전례).

## 1. 조작 — 2×2
| | act_drive 6 | act_drive 18 |
|---|---|---|
| **tau_e 200** | 기준 | B |
| **tau_e 800** | A | C |

- `--eta 0.001 --epsilon 0.6 --baseline 0.0 --trials 400`
- 배선 시드 **0·3·4**(여지 시드만) × 난수열 100~107 × 4조건 = **96런**
- 대조: 같은 배선의 `frozen` 3런
- **지표**: 1차 **가중치 획득률**(A전용 > 0 AND B전용 < 0), 2차 평가 성공률

## 2. 조작 검증  ★필수
1. **tau_e가 듣는가**: tau_e 800에서 학습 후 `kc_out` |Δ|평균이 200보다 **크다**
   (흔적이 오래 남으면 더 많이 갱신된다). 같으면 조작 무효.
2. **act_drive가 듣는가**: 18에서 출력 스파이크가 6보다 많다.
3. **포화 없음**: `max == w_max` 비율 10% 미만.
4. **배선 고정**: 같은 `--seed`에서 `n` 동일.
5. 두 조건 값이 소수점까지 같으면 조작 무효 의심.

## 3. 불변식 확인

- [~] INV-A3/A4/A5 — 해당 없음 (사유: 전체 모델 배선이 이 회로에 없다)
- [~] INV-A6 — 해당 없음 (사유: 평가가 별도 단계, 시행 사이 무자극 600스텝)

- [x] **P18 난수열 반복** — 조건당 8회. **보조 조건 없음**

## 4. 사전 판정 기준
지표는 **가중치 획득률**(24런 중 A전용>0 AND B전용<0인 비율)이다. 기준 조건은 37.5%.

**(a) tau_e 효과**:
- **지지**: tau_e 800의 획득률이 200 대비 **15%p 이상 차이**(양방향 모두 인정 — 늘거나 줄거나)
- **기각**: 차이 5%p 이내

**(b) act_drive 효과**:
- **지지**: act_drive 18의 획득률이 6 대비 **15%p 이상 차이**
- **기각**: 차이 5%p 이내

**(c) w4 구조 고정성**:
- w4의 A전용 부호가 **어떤 조건에서든 양수로 뒤집히는가**.
- 32런(4조건 × 8난수열) 중 **한 번도 안 뒤집히면** 배선이 지배한다는 증거(H022-wiring).

## 5. 이 결과로 새로 알게 되는 것
- **(a) 또는 (b) 지지** → 획득률을 올리는 손잡이를 찾았다. 최적 조건에서 성공률을 재측정하고,
  그 값이 전체 모델의 해당 파라미터(`tau_e` 기본 200)와 어떻게 다른지 본다.
- **둘 다 기각, (c)에서 w4가 안 뒤집힘** → **배선이 학습 가능성을 결정한다**.
  파라미터 조정으로는 못 넘고, 배선 자체(KC 분리·출력 연결)를 설계해야 한다.
  이는 E081의 FlyWire 롱테일 논의로 되돌아가는 것이며, 그때와 달리 **측정이 신뢰 가능하다**.
- **둘 다 기각, w4가 가끔 뒤집힘** → 획득은 확률적이고 두 파라미터는 무관하다.
  다음 후보는 시행 수·탐색 스케줄이다.

## 6. 이 대조가 **식별하지 못하는 것**
- **조건 간 차이 전부**: `--tau-e`와 `--act-drive` 둘. 배선·난수열·eta·회로 전부 동일.
  조작검증 4가 연결 개수로 배선 동일성을 확인한다.
- **의도한 차이**: 자격흔적 시간폭, 행동 주입 세기.
- **지표 상쇄 검토**: 지표가 획득률(빈도)이고 관심 요인은 두 파라미터다. 뺄셈 양변에 안 들어간다.

### 이 결과로도 배제 못 하는 설명
1. **두 파라미터가 상호작용할 수 있다**: 2×2라 주효과와 상호작용을 구분하지만,
   각 칸이 24런이라 상호작용 검출력은 약하다.
2. **여지 시드 3개뿐**: w4가 8/8 실패이므로 실질 표본은 w0·w3의 16런에 가깝다.
3. **tau_e를 늘리면 앞 시행 흔적이 섞인다**: 무자극 600스텝이 tau_e 800에서는 0.75 tau뿐이라
   이월이 남는다. tau_e 효과와 이월 효과가 **분리되지 않는다**.
4. **과제·회로 1종**: 전체 모델로의 이전은 별도 문제다.

## ★ 자격흔적은 **짧아야** 한다
tau_e를 200 → 800으로 늘리면 갱신량은 2배가 되는데(|Δ| 0.224 → 0.427)
획득률은 **52.1% → 16.7%로 떨어진다.** 더 많이 갱신하는데 더 못 배운다.

사전등록 6번에 적은 한계가 그대로 원인으로 보인다:
**무자극 600스텝이 tau_e 800에서는 0.75 tau뿐이라 앞 시행 흔적이 남는다.**
흔적이 길면 **이전 시행의 자극-행동 쌍에 현재 보상이 배정된다** — 신용이 오염된다.
단 이 실험은 tau_e 효과와 이월 효과를 **분리하지 못한다**(6번 3항).

## ★ w4는 구조적 실패가 아니었다
E092에서 w4는 8/8 실패였고 A전용 부호가 8번 모두 음수였다(K33).
여기서 **32런 중 3번 양수로 뒤집혔고**, 최적 조건(tau200/act18)에서 **3/8 획득**했다.
→ 배선이 학습 가능성을 완전히 결정하지는 않는다. **H022-wiring 기각.**
K33의 "배선 의존적"이라는 표현은 유지하되 "구조적으로 불가능"은 아니다.

### 새로 알게 된 것
1. **최적 조건에서 획득률 66.7%, 성공률 37.5%** — 기준(37.5%/25.0%)보다 크게 개선.
   w3는 **8/8 완전 획득**이다.
2. **tau_e는 짧을수록 좋다**(200 ≫ 800). 전체 모델의 기본값도 200이며,
   이 회로에서 더 짧은 쪽(50·100)은 아직 안 봤다.
3. **act_drive는 셀수록 좋다**(6 → 18). 단독으로는 기준 미달이나 tau200에서 +29.2%p다.
   더 센 쪽(36·54)이 계속 좋아지는지 봐야 한다.
4. **읽어내기 효율은 그대로**: 최적 조건에서 16런 중 9런이 평가 100% = 56%
   (E092의 67%와 비슷). 개선은 전부 획득 단계에서 났다.
