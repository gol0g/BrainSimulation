# E074: H004 재판정 — 판정 가능한 설계로

- **등록일**: 2026-09-05
- **상태**: 등록됨
- **검증할 가설**: H004 (대역폭이 병목이다)
- **경쟁 가설**: H005 (연합 방향이 병목이다)

## 배경
E070·E072는 **검출력 부족**으로 판정 불가였다(K12). E073에서 분산의 주 출처가
**환경(0.0177) vs 뇌(0.0085)** 임이 밝혀졌고(K13), **환경 고정 + 뇌 반복**이면
필요 표본이 48 → 11로 줄어든다(P12). 그 설계로 H004를 다시 묻는다.

## 1. 조작
대역폭 **기준 1.0x**(learn 0.08 / reflex 0.15) vs **양쪽 11.25x**(learn 0.30 / reflex 0.05).
**P12 설계**: 환경 3개(env 0·1·2) × 뇌 5반복(brain 0~4) × 2조건 × (수리/정적).
→ 환경별로 따로 판정하고, 환경 간 결과가 갈리면 그것 자체를 보고한다(U5).

공통: `--real-rstdp --crossed --epsilon 0.6 --bias 25 --d1-inhib -400 --direct-inhib -100 --reflex-w 3 --episodes 60`

## 2. 조작 검증  ★필수
1. **전달 생존**: `--bias 300 --bias-at-d1`로 보상 > 0 확인(E072에서 478회). 0이면 중단.
2. **대역폭 변화**: `synapse_count_probe.py`로 learn 3.7x·reflex 0.33x 확인(E070에서 검증됨).
3. **시드 분리 작동**: 환경 고정 시 뇌 시드만 바꿔도 결과가 달라지는지 확인(E073에서 검증됨).
4. 두 조건 결과가 소수점까지 같으면 조작 무효 의심.

## 4. 사전 판정 기준
환경별로 뇌 5반복의 **평균 (수리−정적)** 을 조건별로 낸다. 뇌 반복 표준편차 ≈0.0085이므로
5반복 표준오차 ≈ **0.0038**.
- **H004 지지**: 11.25x가 기준선보다 **0.008 이상 더 음수**(≈2 표준오차)인 환경이 **3개 중 2개 이상**.
- **H004 기각**: 세 환경 모두 차이가 **0.004 이내**(≈1 표준오차).
- **환경 의존(U5/H007)**: 환경마다 부호가 갈리면 → H004 판정 보류하고 **환경 의존성을 새 가설로 승격**.

## 5. 이 결과로 새로 알게 되는 것
- **지지** → 대역폭이 병목이며, 키우면 L2(반사를 이김)에 접근할 수 있다.
- **기각** → 대역폭도 아니다. 가중치(E069)에 이어 두 축이 확정 배제되고 **H005(연합 방향)** 가 유일하게 남는다.
- **환경 의존** → "무엇이 병목인가"보다 **"어떤 조건에서 학습이 작동하는가"** 로 질문이 바뀐다.
  이는 CHARTER의 개념 4조건 중 **일반화** 요건과 직결된다.
- 어느 쪽이든 E070·E072의 미결이 해소된다.

### 이 결과의 의미
"대역폭이 병목인가"는 **환경을 지정하지 않으면 답이 없는 질문**이었다.
같은 조작이 env2에서는 돕고 env0에서는 방해한다.
→ 질문을 **"어떤 환경에서 학습이 작동하는가"** 로 바꾼다(H007).
이는 CHARTER의 개념 4조건 중 **일반화**와 직결된다.
