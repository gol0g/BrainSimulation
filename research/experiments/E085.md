# E085: 이득 효과의 정체 — 다른 경로 학습의 증폭인가

- **등록일**: 2026-09-19
- **상태**: 등록됨
- **검증할 가설**: H016 (D1 하류 전달 이득이 병목 — 이득은 학습에 비특이적으로 작용한다)
- **경쟁 가설**: H016-null(이득은 학습과 무관하게 행동을 바꾼다), H004(KC 경로 특이적)

## 배경 — E084가 남긴 미해결
E084에서 KC 학습을 **하나도 켜지 않고** `kc_d1_w`만 0.5→150으로 올린 조건(C−A)이
평균 **−0.0272**로, 고이득에서 KC 학습을 켠 효과(−0.0148)보다 **컸다**.

네 칸 모두 `--real-rstdp --crossed`(다른 경로 학습)가 켜져 있었으므로 두 설명이 남는다.
1. **증폭 설명**: 이득이 *다른 경로의 학습*을 증폭했다 → 학습을 다 끄면 (c)가 사라져야 한다.
2. **비학습 설명**: 이득 자체가 학습과 무관하게 행동을 바꾼다 → 학습을 다 꺼도 (c)가 남는다.

이 둘은 다음 수를 완전히 갈라놓는다. 1이면 "하류 증폭률"이 병목으로 특정되고,
2라면 우리가 재는 "변조폭 변화"가 학습 지표가 아니라는 뜻이다.

## 1. 조작
`kc_d1_w` 0.5 / 150 × **모든 가소성 끔 / 다른경로만 켬** 2×2. KC 학습은 네 칸 모두 **끈다**.

| | 가소성 전부 끔 (`--no-reward`) | 다른경로 학습 켬 (`--real-rstdp --crossed`) |
|---|---|---|
| **kc_d1_w = 0.5** | P | Q |
| **kc_d1_w = 150** | R | S |

- (R−P) = **학습이 전혀 없을 때의 이득 효과**
- (S−Q) = E084의 (C−A) 재현
- 뇌 5반복, `--env-seed 0`, `--transplant-eval`, `--bias-at-d1`.  = **20런**

## 2. 조작 검증  ★필수
1. **가소성 정지 확인**: P·R 칸에서 학습 시냅스 6종의 학습 전후 |Δ| = 0
   (`--dump-kc-weights` + `eval_freeze_verify.sh` 방식). **0이 아니면 조작 무효.**
2. **이득 조작**: `kc_to_d1` 평균이 0.5 / 150으로 유지되는가(상한 눌림 없음).
3. **연결 동일성**: 네 칸 지문 일치 (`connectivity_check.sh` — E084에서 확인된 항목 재확인).
4. 두 조건 값이 소수점까지 같으면 조작 무효 의심.

- [x] INV-B4 평가 중 가소성 동결

## 4. 사전 판정 기준
**(a) 증폭 설명 지지**: (R−P)가 **0.005 이내** AND (S−Q)가 **0.015 이상 음수**, 각각 5뇌 중 4 이상.
  → 학습이 없으면 이득 효과도 없다 = 이득은 학습을 증폭하는 것이다.
**(b) 비학습 설명 지지**: (R−P)가 **0.015 이상 음수**, 5뇌 중 4 이상.
  → 학습 없이도 이득이 행동을 바꾼다 = 변조폭 변화는 학습 지표가 아니다.
**(c) 둘 다 아님**: 중간값이면 **보류**하고 반복을 늘린다. 사후에 기준을 바꾸지 않는다.

## 5. 이 결과로 새로 알게 되는 것
- **(a)** → 병목이 **하류 증폭률**로 특정된다. H016이 주력이 되고, 다음 축은
  `d1_to_direct_weight`·`direct_to_motor_weight`(INV-A3/A5로 고정돼 있던 값들)가 된다.
- **(b)** → **우리 지표가 학습을 재지 못한다.** 가중치를 바꾸지 않아도 배선만으로 같은 크기가 나온다는 뜻.
  E069 이후 모든 행동 결과의 해석이 무너지고, 외부 검토 제안대로 **최소 회로**에서
  학습-보상 관계를 먼저 성립시키는 쪽으로 간다.
- **(c)** → 이득 효과가 학습 유무에 부분적으로만 의존한다. 두 성분을 분리하는 설계가 더 필요하다.

## 6. 이 대조가 **식별하지 못하는 것**
- **네 칸의 차이 전부**: `--kc-d1-w`(0.5/150)와 `--no-reward` vs `--real-rstdp --crossed` 둘뿐.
  KC 학습(`--kc-rstdp`)은 네 칸 모두 **끈다**. 연결 지문은 E084에서 네 칸 일치를 실측했다.
- **의도한 차이**: 위 둘.
- **지표가 관심 요인을 상쇄하지 않는가**: 관심 요인(이득)은 칸 간 축이고 지표는 이식 평가의
  변조폭 변화다. 뺄셈 양변에 들어가지 않는다.

### 이 결과로도 배제 못 하는 설명
1. **`--no-reward`가 가소성을 완전히 멈추는지**: 조작검증 1에서 |Δ|=0을 확인하지만,
   이식 목록 **6종 밖의 경로**가 학습하면 잡히지 않는다. 이 목록의 완전성은 여전히 미검증이다.
2. **환경 1개**(`--env-seed 0`): K14의 환경별 부호 반전 전례가 있다. 일반 결론이 아니다.
3. **`--real-rstdp`와 `--crossed`를 묶어서 켠다**: 둘 중 어느 쪽이 증폭되는지는 구분 못 한다.
4. **이득 두 수준만**: 0.5와 150 사이의 형태(선형/문턱)는 알 수 없다.
