# E081: KC 가중치 다양성 — D1을 100개 뉴런으로 되돌리기

- **등록일**: 2026-09-16
- **상태**: 등록됨
- **검증할 가설**: H015 (D1 뉴런들이 동일 입력을 받아 집단이 1개처럼 작동)
- **경쟁 가설**: H015-null(다양성을 만들어도 무관), H011(전반적 배선)

## 배경
`d1_diversity_probe`: D1 100개 뉴런의 **변동계수 0.101**, 발화 뉴런 **100%**.
`FixedProbability` + `Constant` 가중치라 모든 뉴런이 통계적으로 같은 입력을 받는다.
→ E080에서 측면억제가 실패한 이유(**가릴 승자가 없다**), E079에서 KC 신용할당이 무효인 이유(**하류 평균화**).

FlyWire 실측은 롱테일이다: 연결당 시냅스 **중앙값 2 / 평균 3.6 / p99 32 / max 2405**.
MBON 96개가 각자 **다른 KC 조합**을 받는다.

## 1. 조작
`--kc-gamma`: KC→D1 가중치 초기화를 `Constant` → **감마분포**(shape 0.5, 평균 유지)로.
- shape<1이면 **롱테일** — 대부분 약하고 소수가 강함(FlyWire 형태)
- 연결 구조(sparsity)는 건드리지 않는다 — **가중치 분포만** 바꾸는 최소 조작

## 2. 조작 검증  ★필수
1. **CV가 오르는가**: `d1_diversity_probe`로 변동계수 측정.
   현재 0.101 → **0.5 이상**이면 다양성 생성 성공
2. **발화 뉴런 비율이 100% 미만으로 내려가는가** (일부만 반응 = 선택성)
3. **d1 절대발화가 붕괴하지 않는가** (50 미만이면 과도)
4. 두 조건 결과가 소수점까지 같으면 조작 무효 의심(전례 5회)

## 4. 사전 판정 기준
**(a) 다양성 생성** — 조작 검증:
- **지지**: CV **0.5 이상** (3시드 모두) 이고 절대발화 50 이상 유지
- **기각**: CV 0.2 미만 → 감마분포로는 다양성이 안 생긴다

**(b) 변별 증가** — (a) 통과 시:
- **지지**: d1 측성차이가 기존(평균 23.1) 대비 **2배 이상**, 3시드 모두
- **기각**: 2배 미만

**(c) 행동 효과** — (b) 통과 시:
- **H015 지지**: (수리−정적)이 기본보다 **0.008 이상 더 음수**, 3뇌 중 2 이상 방향 일치
- **기각**: 0.003 이내

## 5. 이 결과로 새로 알게 되는 것
- **(a)(b)(c) 지지** → 병목이 **연결 다양성 부재**로 특정된다. FlyWire 롱테일 구조를 따른 것이
  처음으로 기능하며, L2(반사를 이김)로 가는 경로가 열린다.
- **(a)(b) 지지, (c) 기각** → 변별은 생겼으나 행동에 안 닿는다. 병목이 D1 **하류**(direct/motor)다.
  남은 축은 K16(밀도 100배 과밀, 반사 5배 초과)이며 **H011**로 이동한다.
- **(a) 기각** → 가중치 분포로는 부족하다. **연결 구조 자체**(뉴런별 선택적 KC 그룹)를 바꿔야 한다.

### ⚠ 1차 조작검증 무효 — INV-A4 위반
`d1_diversity_probe.py`가 `d1_inhibition`을 설정하지 않았다. **기본값 0.0 = D1 포화**.
사전등록 3번에는 `[x] INV-A4 d1_inhibition = -400`으로 체크돼 있었으나,
그 체크는 본실험만 생각한 것이었고 실제로 실행한 프로브는 불변식 밖이었다.
→ 규약 **P15** 신설. 1차·2차(`e081_check.sh`, `e081b_dose.sh`) 결과 **전부 폐기**.

부수 버그: 프로브가 집단 크기를 `max(spike_ids)+1`로 추정했다.
**포화 상태에서만 우연히 맞는 코드**였고 포화를 풀자 broadcast 오류로 즉시 깨졌다.
`num_neurons` 고정값으로 교체.

### 새로 알게 된 것
1. **H015 기각**: D1은 1개처럼 작동하지 않는다. CV 1.18, 발화뉴런 57%.
   KC는 **6%만 발화**하는 정상 스파스 코딩 — 버섯체는 이미 제 일을 하고 있었다.
2. **H014 흔들림**: "D1 포화(~667 고정)"라는 근거가 같은 아티팩트였다. 재검토 대상.
3. **새 정량 사실**: KC→D1 경로는 기본 가중치에서 D1 발화의 **+0.6%**만 기여한다.
   40배로 올려도 +11.4%. 영향력이 구조적으로 작다 → **다음 축은 KC 경로 영향력 비율**.
4. **측정 도구가 병증에 의존하고 있었다**: 포화를 고치자 프로브가 깨졌다.
