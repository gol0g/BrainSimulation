## 5. 이 결과로 새로 알게 되는 것  ★필수
전체 모델(KC 확장층 + KC→motor R-STDP, 형성 표현)이 요소 연합으로는 풀 수 없는 과제 — 같은 자극의 정답이 맥락에 따라 반대 — 를 배우는지. 배우면 KC 층이 맥락 결합 부호화로 '같은 자극, 다른 의미'(헌장 L4 의 전 단계)를 지원한다. 요소식이면 이 구조의 KC 표현은 단순 흥분성 맥락만으로 맥락별 집합을 갈라 주지 못한다(결합 형성이 필요). 부분이면 어느 맥락이 지는지가 공유 KC 갈등(켬만) 대 결합 KC 부족(끔만)을 가른다.

## 6. 이 대조가 **식별하지 못하는 것**  ★필수 (2026-09-18 신설 — E082가 여기서 뚫렸다)
- **두 조건의 차이 전부 나열**: (끔 평가 대 켬 평가) 맥락 집단 발화 → KC 입력 추가 → KC 반응 집합·총활동 변화 → motor 구동 변화. (학습 대 무학습) KC→motor 가중치(쌍조건 3,000시행)뿐 — 같은 뇌·같은 맥락 연결.
- **의도한 차이는 그중 무엇인가**: 학습이 맥락별로 다른 KC→motor 사상을 만들었는가(e_off·e_on 의 부호). 맥락 자체의 조향 치우침·KC 총활동 변화는 무학습 켬 평가를 빼서 제거한다.
- **지표가 관심 요인을 상쇄하지 않는가**: e_off·e_on 은 맥락마다 따로 학습 − 무학습. 맥락 의존 학습이면 두 값의 부호가 반대여야 하고, 요소식(맥락 무시)이면 같아진다 — 상쇄 아님.
- **이 결과로도 배제 못 하는 설명**:
  1. 맥락이 흥분성 균일 전류(두 쪽 모든 KC 에 같은 값, 정정 1) 하나뿐 — KC 별 맥락 입력 이질성이 없어 결합 KC 는 자극 입력이 문턱 바로 아래인 KC 가 맡는다. 실패해도 '맥락 의존 학습 불가'가 아니라 '이 맥락 입력 형태로는 불가'다(이질 맥락·억제 성분·결합 형성은 미시험).
  2. I* 하나 — 다른 세기에서의 결과는 모른다(보정 규칙이 고른 칸).
  3. 맥락 켬은 KC 총활동을 늘려 motor 출력 압축(K104)에 들어갈 수 있다 — 크기 비교는 단독 과제(E162)와 직접 못 한다.
  4. 개발 뇌 10~14, 시행 난수열 env seed 0, 3,000시행 한 길이.
