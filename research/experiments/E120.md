## 4. 사전 판정 기준  ★필수 (실행 전에 못박는다)
뇌별 효과 e_b(n) = 학습 n 사후 − 무학습 사후(이식 변조폭, 소수 4자리 반올림, 음수 = 정답). n=5는 E119 값(−0.1033, −0.0724, −0.0690, −0.0809, −0.0607 — **이미 알고 있음**). 무학습 사후는 무학습 15 값(무학습 5와 같아야 함 — 2절).
누적 증분 d_b = e_b(15) − e_b(5). 잡음 문턱 0.03(관측 최대 재실행 흔들림), 최소 의미 효과 0.10(E119와 같음).
- **A 누적·도달(H045 지지, 학습량 조건부)**: e_b(15) ≤ −0.10 뇌 ≥4/5 **그리고** d_b ≤ −0.03 뇌 ≥4/5
- **C 누적·미도달**: d_b ≤ −0.03 뇌 ≥4/5 이나 e_b(15) ≤ −0.10은 <4/5
- **B 포화(H045-sat 쪽)**: |d_b| < 0.03 뇌 ≥4/5
- **H045-drift**: d_b ≥ +0.03 뇌 ≥4/5
- **보류**: 그 밖, 또는 조작검증 실패
- 주(19:18, 실행 전): 알려진 e(5)에서는 d ≤ −0.03이면 b10·b11·b13은 자동으로 e(15) ≤ −0.10이 된다(b12는 (−0.10, −0.099], b14는 (−0.10, −0.0907] 구간만 C 가능). 따라서 C는 사실상 성립하지 않고 판정은 A·B·drift·보류로 갈린다. 규칙은 바꾸지 않는다.
- 부지표(판정 불변): 단조성 e(5) > e(10) > e(15)(더 음수로) 뇌 수, 사후 정답률, 보상 횟수, `[판정경로]` 불일치율.
- 반복 수: 뇌 5(같은 뇌 짝, E119 표본). 귀무 대조: 같은 뇌 무학습(도파민 0, 15 에피소드 같은 처리량).
- **결과별 다음 결정**:
  - A → H045 지지(학습량 조건부), 분기 종료. 다음 능력(미학습 자극·조합 전이)을 전체 모델 반사 0·학습 15 에피소드 설정에서.
  - C → 학습은 누적되지만 느리다(최소 회로 K48 반전과 같은 유형). 같은 축(학습량)을 더 늘리지 않는다(조건 6). 분기 종료, "크기 미달·느린 누적"을 미해결로 남기고 전이 능력으로(반사 0·학습 15).
  - B → 크기 한계는 학습량이 아니라 통합 요소 → E121(분기 3/3): 최소 회로와 요소 맞바꾸기, 첫 후보 KC 표현 겹침.
  - drift → 학습이 쌓일수록 공통 상승이 지배 — E121에서 원인 요소(경계·공통 상승) 하나.
  - 보류 → 측정부터(막힌 경로 확인). 분기 상한 3에 도달하면 미해결로 두고 전이를 최소 회로(K50)에서 시작.
- **예산**: 15런, GPU 약 2.5시간(E119 5 에피소드 런 ≈ 5분 실측, 학습 구간 비례 추정).

## 5. 이 결과로 새로 알게 되는 것  ★필수
E119의 작은 크기(평균 −0.077)가 **학습량 부족**(누적 → 늘리면 커짐)인지 **통합된 경로의 한계**(포화)인지를 가른다. 누적이면 전체 모델은 반대 반사가 없을 때 느리지만 누적되는 매핑 학습을 하는 것이고 전이 단계로 간다. 포화면 능력 손실 지점은 학습량이 아닌 통합 요소이며 마지막 분기 실험(E121)을 요소 맞바꾸기에 쓴다.
