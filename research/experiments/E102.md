# E102: 반전 중 처벌·보상이 옛/새 연합 가중치를 실제로 어떻게 바꾸는가

- **등록일**: 2026-09-27
- **상태**: 완료 — (a) 처벌 정상, (b) H031-normal(방향 기준) — 단 배선 5·6은 0을 넘지 못함 (2026-09-27)
- **검증할 가설**: H031 — 반전 중 처벌이 옛 연합(A전용 KC→out_L)을 깎지 못한다
- **경쟁 가설**: H031-slow(깎지만 순 균형이 옛 쪽), H031-normal(가중치는 새 쪽으로 가는데 행동이 안 뒤집힘)

## 1. 조작 (Manipulation)
**측정 실험**이다(조건 조작 없음). 새 옵션 `--trace-file`(minimal_circuit.py, 2026-09-27 추가):
매 시행 **도파민 직전 자격흔적 e**와 **도파민 후 가중치 g**를 KC(전시냅스)별 합으로 저장 + (자극·행동·보상·nl·nr). 기기에서 **읽기만** 한다.
- 설정: K38 = E100과 동일(`--w-max 20`, reversal, `--trials 800`)
- 표본: 배선 **5·6·7** × 난수열 **300~303** = **12런** (E100 rev와 같은 쌍 → 직접 대조)
- 선행: **회귀 검사** `scripts/regression_mincirc.sh`(K38 24/24) — 코드를 바꿨으므로 필수
- 원본 npz: `research/experiments/traces/E102/`(git 제외, 대용량). 런별 요약: `logs/E102/*_summary.log`(추적됨)
- 분석: `scripts/analyze_e102.py`(런마다 WSL에서 실행 → 요약), 판정 `scripts/judge_e102.py`

**그룹 정의**: A전용 KC = 평가 후 A에만 반응한 KC(학습 후 집합, `kc_a − kc_b`). B전용 동일.
**사건**: 반전 구간(t ≥ 400)에서
- P_A = A 시행 · 행동 L(옛 정답) · 처벌 → Δg(A전용→L) = g_l[t] − g_l[t−1] 의 A전용 합
- R_A = A 시행 · 행동 R(새 정답) · 보상 → Δg(A전용→R)
- 순 변화 D_A = [g_l − g_r](A전용) 의 반전 구간 끝 − 시작 (양수 감소가 새 방향)
- B도 대칭(B전용, 옛 정답 R, 새 정답 L)

## 4. 사전 판정 기준  ★필수 (실행 전에 못박는다)
런별로 반전 구간 P_A 평균(처벌 사건의 옛 연합 Δg)을 구한다. 사건이 5개 미만인 런은 제외(수를 보고).
**(a) 처벌 효과** (A 기준, B는 같은 규칙으로 보조 보고):
- **H031 지지(깎지 못함)**: P_A 평균 ≥ 0 인 런이 유효 런의 **≥ 10/12 비율(≥83%)**
- **처벌 정상**: P_A 평균 < 0 인 런이 **≥ 83%**
- 그 외 **보류**
**(b) 순 균형** ((a)가 "처벌 정상"일 때만):
- D_A < 0 (새 방향으로 이동)인 런 ≥ 83% → **H031-normal**(가중치는 뒤집히는데 행동이 안 뒤집힘 → 판독·WTA 쪽 조사)
- D_A ≥ 0 인 런 ≥ 83% → **H031-slow**(처벌은 깎지만 다른 사건이 옛 연합을 되살림 → 사건별 기여 분해 보고)
- 그 외 보류
**(c) 보조 보고(판정 아님)**: 처벌 사건 직전 e(A전용→L) 부호 분포, 옛 행동 보상 사건(탐색이 옛 행동을 골랐을 때는 반전 후 처벌) 외에 옛 연합을 올리는 사건 종류별 Δg 합.

- **예산**: 회귀 24 + 추적 12 = 36런. 4시간 초과 시 중단, 보류로 기록.

## 5. 이 결과로 새로 알게 되는 것  ★필수
반전 실패가 **가중치 수준**(처벌이 옛 연합을 못 깎음 / 순 균형이 옛 쪽)의 문제인지, **가중치는 바뀌는데 행동 판독**에서 막히는지.
세 경쟁 가설이 각각 다른 수리(자격흔적·도파민 규칙 / 사건 균형·탐색 / WTA·판독)를 가리킨다 — 다음 수리 대상을 정한다.

## 6. 이 대조가 **식별하지 못하는 것**  ★필수
- **두 조건의 차이 전부 나열**: 추적 런 vs E100 rev — `--trace-file` 유무뿐(읽기 전용). 동일성은 2절에서 검증한다.
  획득 구간 vs 반전 구간 — 규칙, 가중치 초기 상태, 행동 분포가 모두 다르다(비교는 부호 확인용, 크기 비교 아님).
- **의도한 차이는 그중 무엇인가**: 없음(측정). 사건 종류별 Δg가 관심 대상.
- **지표가 관심 요인을 상쇄하지 않는가**: Δg를 **KC 그룹별 합**으로 본다 — A전용 KC 안에서 증감이 섞이면 상쇄될 수 있다. 그룹 안 분포(증가 KC 비율)를 보조로 낸다.
- **이 결과로도 배제 못 하는 설명**:
  1. A전용/B전용 집합은 **학습 후** 정의 — 반전 중 KC 반응이 바뀌면 집합이 흔들린다(KC는 가소성 없는 입력층이라 크지 않을 것으로 예상, 확인 안 함).
  2. 공유 KC(A·B 모두 반응)의 기여는 이 그룹 분석에서 빠진다 — 판독에 크게 기여할 수 있다.
  3. 시행 단위 Δg는 gap 구간의 도파민 0 기간을 포함 — 도파민 0이면 가중치가 안 바뀌므로(K26) 영향 없음으로 가정.
  4. 12런·배선 3개 범위.

### 해석 (범위 한정)
1. **사전기준 (b)의 허점**: "순 변화가 새 방향"만 보고 **0을 넘었는지**(실제 역전)는 보지 않았다. 판정은 기준대로 두되,
   배선 5·6은 400시행 동안 옛 연합 우세의 **약 25~35%만** 되돌렸다 — 사실상 "느림(slow)"이다. 배선 7만 가중치가 역전됐다.
2. **처벌/보상 크기 비대칭이 실재한다**(사건당 13~33배). w_max 20·g≈0.6의 소프트 경계 예측(약 1/30)과 맞다.
   그러나 E101에서 w_max 2로 이 비대칭을 줄여도 반전 0/24였다 → 비대칭은 **느림의 한 원인이지만 충분조건이 아니다**.
3. **신용 할당 누수**: 새 행동(R)을 보상받은 A 시행에서 **옛 연합 A→L도 강해졌다**(반전 구간 옛 연합 기여: 처벌 −7.85, 새 행동 보상 **+4.23**, 12런 평균).
   A전용 KC가 켜진 동안 옛 출력(L)도 발화해 자격흔적이 양으로 남기 때문으로 보인다(행동 구동은 선택 출력만 올리고 비선택 출력을 끄지 않는다).
4. **배선 7: 가중치는 역전됐는데 행동은 편향(52%)** — A전용 그룹 밖(공유 KC)이나 판독(WTA)에서 막힌다. 이 분석은 공유 KC를 보지 않았다.
