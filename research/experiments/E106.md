- **경쟁 가설**: H034-noncontingent(w_max 2에서는 수반성 없는 보상으로도 학습된다)

## 1. 조작 (Manipulation)
K38 + `--w-max 2`. 배선 **5·6·7·8**(frozen 57/44/48/0 — E099 확정, 선천 천장 아님) × 난수열 **400~407**(미사용).
learn(보상 계열 저장) 32런 + shuffled(같은 보상 계열을 시행에 무작위 재배정 — 총량 동일, 수반성만 제거) 32런 = 64런.
러너 `scripts/e106_main.sh`, 판정 `scripts/judge_e106.py`.

## 2. 조작 검증 (Manipulation check)  ★필수
- shuffled 보상 총량 = 짝 learn (32/32 일치). 불일치 쌍은 무효.
- frozen은 배선별 결정론(K43) — 이 배선들은 frozen <60이라 선천 성공이 판정에 섞이지 않는다.

- [~] INV-A3/A4/A5 — 해당 없음 (사유: 전체 모델 배선이 이 회로에 없다)
- [~] INV-A6 — 해당 없음 (사유: 평가가 별도 단계)
- [x] INV-B1 지표 — 평가 성공률(≥90%)
- [x] INV-B2 무학습 대조 — shuffled(수반성 제거), frozen(E099, 배선별 결정론)

## 4. 사전 판정 기준  ★필수 (실행 전에 못박는다)
성공 = 평가 ≥90%.
- **귀속 성립**: learn ≥ **28/32** 그리고 shuffled ≤ **4/32** → H034 귀속 부분 지지 → E105의 (a)(c)(d)와 합쳐 **w_max 2 기본값 채택**
- **귀속 실패**: learn ≤ 16/32 또는 shuffled ≥ 12/32
- 그 외 **보류**
- **예산**: 64런, 3시간.

## 5. 이 결과로 새로 알게 되는 것  ★필수
w_max 2의 학습이 보상 **수반성**에 의존하는지 — 선천 천장이 섞이지 않은 표본에서의 깨끗한 답. 채택되면 최소 회로의 기본 설정이 확정되고 유지 관문으로 간다.
