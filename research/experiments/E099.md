## 2. 조작 검증 (Manipulation check)  ★필수
- `shuffled`의 `reward=`가 같은 배선·난수열 `learn`의 `reward=`와 **같아야** 한다(총량 보존). 다르면 해당 짝 무효.
- `noreward`·`frozen`의 `reward=`는 **0.0**이어야 한다.
- `frozen`은 eta=0: 같은 배선에서 난수열이 달라도 평가가 학습 없이 정해진다 — learn과 달라야 조작이 들은 것.
- **learn과 shuffled의 평가 분포가 소수점까지 같으면 조작 무효를 먼저 의심한다.**
- 조건 로직 자체는 E092(K32)에서 검증됨. 이번엔 새 설정에서 위 수치로 재확인.

## 6. 이 대조가 **식별하지 못하는 것**  ★필수
- **두 조건의 차이 전부 나열**: learn vs shuffled — 보상이 행동·자극에 수반되는지만 다르다(총량·배선·난수열 동일). 단 shuffled는 행동이 달라지면 탐색 궤적도 달라져 이후 동시활동 분포가 달라진다(결과로서의 차이).
  learn vs frozen — 가소성(eta) 유무와 보상 유무 둘 다. learn vs noreward — 도파민 유무(가소성은 있으나 보상·벌 모두 0 — `set_dopamine(syn, 0.0)`).
- **의도한 차이는 그중 무엇인가**: 일반화 판정은 learn 단독 성공률, 귀속은 learn−shuffled(수반성).
- **지표가 관심 요인을 상쇄하지 않는가**: 뺄셈 지표 안 씀. 조건별 성공 개수만 센다.
- **이 결과로도 배제 못 하는 설명**:
  1. 배선 시드 5~9도 **같은 생성 분포**에서 뽑혔다 — 다른 회로 크기·희소도·패턴 겹침에서의 일반화는 말하지 못한다.
  2. 과제가 두 자극–두 행동 고정 연합 하나다 — 개념·전이 능력은 전혀 다루지 않는다.
  3. 90% 임계는 이분법 지표다 — 88%와 92%의 차이를 과장할 수 있다. 원 정답률 분포를 함께 보고한다.
  4. 전체 모델로 옮겨진다는 증거가 아니다(E098: tau 단독 이식은 검출불가).

### 판정 (사전기준 대비)
- **조작검증: 통과** — shuffled 보상 총량 = 짝 learn, noreward·frozen 보상 0.
- **(a) 일반화: 지지** — learn 성공(≥90%) **38/40** (기준 ≥32). 100%도 38/40.
- **(b) 학습 귀속: 성립(경계)** — shuffled **8/40**(기준 ≤8), frozen **4/20**(기준 ≤4). 둘 다 경계값에 정확히 걸렸다.
- **(c) 파괴: 관측 없음** — 배선 1·2 learn 16/16이 frozen 100% 유지.

### 해석 (범위 한정)
1. **(b)가 경계인 이유는 배선 9다.** 배선 9는 학습 없이 이미 100%(frozen 4/4)이고, shuffled 성공 8개 중 7개가 배선 9다.
   사후 관찰로, 기준선이 낮은 배선 5~8만 보면 learn **30/32**, shuffled **1/32**, frozen **0/16** — 귀속은 경계가 아니라 뚜렷하다.
   (판정은 사전기준대로 "성립"이며, 이 분해는 판정을 바꾸지 않는다.)
2. **실패 2런(w5 t202 = 57, w7 t205 = 48)은 frozen 값 그대로** — 학습이 일어나지 않은 것이지 파괴가 아니다. K29의 "이산적 학습"과 같은 모양.
3. **noreward = frozen (20/20 동일)**: 도파민 0이면 가소성이 멈추므로(K26) 설계상 예상된 결과다. 조작 무효가 아니라 **noreward가 frozen과 독립인 대조가 아니다**라는 뜻. 이후 설계에서 noreward를 따로 둘 이유가 없다.
4. frozen은 같은 배선에서 난수열이 달라도 값이 같다 — 무학습 greedy 평가는 배선만으로 정해진다(평가 순서 난수는 결과를 바꾸지 않음).
5. **배제 못 하는 것**(6절 그대로): 같은 생성 분포의 배선, 고정 연합 하나, 90% 이분 임계, 전체 모델로의 이전은 무관.
