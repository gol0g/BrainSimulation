# E080: D1 측면억제 — 출력단 경쟁으로 변별 만들기

- **등록일**: 2026-09-16
- **상태**: 등록됨
- **검증할 가설**: H014 (병목은 출력단)
- **경쟁 가설**: H011 (전반적 배선), H014-null (경쟁을 넣어도 무관)

## 배경
E079: KC에 신용 할당을 만들어도(std 0→4.33) 행동 효과는 **+0.0005**(변화 없음).
병목이 KC 하류에 있다.

**구조적 발견**: 현재 `d1_inhib`는 **전역 억제**다 — 하나의 억제 집단이 D1 전체를 균일하게 누른다.
FlyWire의 MBON→MBON 억제(50%)는 **출력끼리 경쟁**하는 측면 억제다.
전역 억제는 전체를 낮출 뿐 **승자를 가리지 못하고**, 측면 억제는 강한 쪽이 약한 쪽을 눌러 **변별을 만든다.**
→ "포화를 풀어도 변별이 안 생기던" 현상(C41/C56)과 정합한다.

## 1. 조작
`--d1-lateral <값>`: D1 좌↔우 **교차 억제** 신설(sparsity 0.15).
- 강도 4수준: **0(기존) / −20 / −60 / −150**
- 뇌 3반복 × 4강도 × (수리/정적) = **24런**
- 공통: `--real-rstdp --crossed --kc-rstdp --epsilon 0.6 --bias 25 --d1-inhib -400 --direct-inhib -100 --reflex-w 3 --episodes 60`
  (E079에서 신용할당이 확인됐으므로 `--kc-rstdp`를 켠 채로 간다)

## 2. 조작 검증  ★필수
1. **시냅스가 실제로 생기는가**: 빌드 로그에 `[E080] D1 측면억제` 출력 확인
2. **d1 변별이 생기는가**: `pathway_transfer_probe.py`로 d1 측성차이 측정.
   현재 −400 전역억제에서 d1 측성차이는 3.5~107(시드 의존, 대부분 한 자릿수).
   측면억제 추가 후 **일관되게 커지면** 조작이 듣는 것.
3. **과억제 확인**: d1 절대발화가 0에 가까워지면 신호가 죽은 것 → 강도를 낮춘다
4. 두 조건 결과가 소수점까지 같으면 조작 무효 의심(전례 5회)

## 4. 사전 판정 기준
**(a) 변별 생성** — 조작 검증:
- **지지**: d1 측성차이가 3시드 모두에서 기존(0 강도) 대비 **2배 이상**
- **기각**: 어느 강도에서도 2배를 못 넘거나, 절대발화가 50 미만으로 붕괴

**(b) 행동 효과** — (a) 통과 강도에서:
- **H014 지지**: (수리−정적)이 0 강도보다 **0.008 이상 더 음수**, 3뇌 중 2 이상 방향 일치
- **H014 기각**: 차이 **0.003 이내** → 출력단 경쟁도 아니다 → **H011(전반적 배선)로 이동**

## 5. 이 결과로 새로 알게 되는 것
- **(a)(b) 지지** → 병목이 **출력단 경쟁 부재**로 특정된다. FlyWire 구조를 따라간 것이 처음으로 기능하며,
  L2(반사를 이김)로 가는 경로가 열린다.
- **(a) 지지, (b) 기각** → 변별은 생겼으나 행동에 안 닿는다. 병목이 **더 하류**(direct/motor)이거나
  전반적 배선(H011)이다. 그러면 남은 축은 K16(밀도 100배 과밀, 반사 5배 초과)뿐이다.
- **(a) 기각** → 측면 억제로는 변별이 안 생긴다. D1 집단 **분할**(좌/우 각 4~8개)로 설계를 키운다.

### 판정: **(a) 기각** → 본 실험(b) 미실시
| 사전 기준 | 실측 | 결과 |
|---|---|---|
| 지지: 3시드 **모두** 2배 이상 | −60에서 seed1만 3.4배, seed0은 1.06배 | **미달** |
| 기각: 어느 강도도 2배 못 넘음 | 평균 최대 1.66배 | **해당** |

**측면 억제만으로는 변별이 생기지 않는다.** −60에서 seed1이 3.4배로 반응했으나
시드 의존적이고 seed0은 거의 무반응이다. −150은 과억제로 오히려 감소.

### 사전등록이 예고한 분기
> "(a) 기각 → 측면 억제로는 변별이 안 생긴다. **D1 집단 분할**(좌/우 각 4~8개)로 설계를 키운다."

이 분기가 발동한다. 좌↔우 **2개 사이의 경쟁**으로는 부족하며,
FlyWire처럼 **출력 집단 자체를 여러 개로 나눠야** 할 가능성이 크다
(실측 MBON 96개 / 우리 2개).
