## B. 현재 믿을 수 있는 주장 (3개)

2. **(관측 — 사후 탐색)** 반응 KC 의 같은 쪽 쏠림은 선택성이 약한 KC(반응 KC 의 약 절반)에 몰려 있다: 그중 같은 쪽이 정답인 KC 는 같은 쪽으로 배우고, 교차가 정답인 KC 는 거의 배우지 않는다. 선택성이 강한 KC 는 양방향 대칭이다. 교차 칸(X·A·Y·B)이 약한 까닭과 맞다 — 약한 KC 들이 모든 시행에 같은 쪽 구동을 더한다.
3. **(해석)** 선택성이 약한 KC 는 두 시행 종류(정답 같은 쪽·교차)에서 비슷하게 활동하므로, 그 학습은 '실행한 쪽 × 도파민' 의 누적에 좌우된다. 같은 쪽으로 끌리는 길은 둘이다: **(M1) 결과 빈도 비대칭** — 같은 쪽 실행이 더 자주 보상받는다(이미 배운 같은 쪽 칸이 되먹임); **(M2) 흔적 크기 비대칭** — 같은 실행·같은 도파민이라도 같은 쪽 경로에 쌓이는 흔적이 교차 경로보다 크다(자극 쪽 motor 의 동시 활동 등). 두 길은 처방이 다르다(M1 → 실행 쪽별 기준선, M2 → 경로별 흔적 크기 정규화).

**설계**: E200 커맨드 그대로 + 읽기 전용 계측(새 플래그): 매 시행 도파민 방출 직전에 KC→motor 4경로의 e·g 를, 보상 창 뒤 도파민을 0 으로 되돌린 직후(경로·KC 정규화 전)에 g 를 당겨 시냅스별 Δg 를 얻는다. KC 별 경로 평균(np.add.at)으로 x = Δg(교차) − Δg(같은 쪽)을 만들고, 시행을 (실행 motor 가 자극 쪽인가 = S / 반대 = C) × (보상 + / 무보상 −) 네 범주로 나눠 KC 마다 누적한다. 시행별 요약(선택성 약한·강한 반응 KC 집단의 평균 x·e, DA, 실행 쪽, 정답 종류, 보상)도 남긴다. 학습만(평가 없음), 뇌마다 3,000시행 약 23분.
**분해(정의 — 결과 전 고정)**: 선택성 약한 반응 KC 집단 평균 x 를 시행 t 마다 x_t, 범주 c 의 도파민 합 W_c = Σ DA_t, 단위 도파민당 변화 m_c = Σ x_t / W_c 라 하면 D_obs = Σ_c W_c·m_c(정확). 짝 범주(S,+)↔(C,+)·(S,−)↔(C,−)마다 μ = (|m_S| + |m_C|)/2, d = (m_S + m_C)/2 로 두면 D_obs = D_freq + D_mag, **D_freq** = Σ μ·(W_C − W_S)(같은 크기에서 도파민 합의 비대칭), **D_mag** = Σ d·(W_S + W_C)(같은 도파민에서 크기 비대칭).
**판정**: 계측 검증 실패 → 보류. 뇌마다: |D_mag| ≥ 2·|D_freq| 이고 D_mag 와 D_obs 의 부호가 같으면 M2, |D_freq| ≥ 2·|D_mag| 이고 부호가 같으면 M1, 그 밖 혼합. 종합: M2 ≥ 4/5 → H123 / M1 ≥ 4/5 → H123-alt / 그 밖 혼합. (보고) 선택성 강한 KC 의 같은 분해, 범주별 N·W·m, 실행 쪽별 보상률, 같은 쪽/교차 경로의 e 크기 비.
