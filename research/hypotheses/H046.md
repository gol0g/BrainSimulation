# H046: 좌우 공통 KC 입력이 전체 모델 반사 0 학습 효과의 크기를 제한한다

- **상태**: 활성 (E121 사전등록 2026-09-28)
- **현재 신뢰도**: 낮음 — 근거는 구조 차이(최소 회로 KC 는 감각 입력만, 전체 모델 KC 는 IT·연합·언어·목표·사회 공통 입력을 양쪽에 받음)와 E119·E120의 크기 포화뿐. 원래 후보 "KC 표현 겹침"은 경로 검사(kcsets 공유 수 불변)로 이 조작과 분리됨
- **경쟁 가설**: H046-null(무관), H046-help(공통 입력이 KC 활동·판독 권한을 키워 오히려 도움)

## 진술
KC 가 좌/우 눈 입력만 받도록 공통 입력 12개 집단 가중치를 0으로 하면(나머지 E119 반사 0과 같음) 학습 효과가 커져 −0.10을 넘는다.

## 예측
- **맞다면**: e_0 ≤ −0.10 뇌 ≥4/5 그리고 Δ = e_0 − e_1 ≤ −0.03 뇌 ≥4/5 (뇌 10~14)
- **H046-null**: |Δ| < 0.03 뇌 ≥4/5
- **H046-help**: Δ ≥ +0.03 뇌 ≥4/5
