# H089: 망 안 형성 표현에서는 보상 창 흔적 동결(호스트 가소성 제어) 없이도 학습 효과가 남는다

- **상태**: 활성 — 시험 중 E166(사전등록 2026-10-10, 기준 고정 01:34:13)
- **현재 신뢰도**: 미정 — 근거: 형성 표현은 good·bad KC 를 가르고 발화 KC 를 정리해(K87·K94) 보상 창의 비선택 흔적이 줄 수 있다(추론). 반대 근거: 보상 창 흔적은 자극을 끈 뒤 양쪽 motor 의 발화에서 생기므로(K75·E140) KC 표현과 무관할 수 있다 — 기본 표현에서는 동결을 빼면 효과가 약 1/3(E119 대 E141)
- **경쟁 가설**: H089-null(손실 — 호스트 동결이 형성 표현에서도 필요)
- **범위**: 뇌 16~20, 반사 0, 500시행, 고정 순환 망 안 형성 가중치(E161)

## 진술
보상 창 동안의 흔적 생성 동결을 빼도, 망 안 형성 표현을 실은 전체 모델은 같은 뇌 동결 학습 효과의 80% 이상을 낸다(q_F ≥ 0.80, ≥ 4/5).

## 예측
- **맞다면**: q_F ≥ 0.80 ≥ 4/5, q_D(기본 표현)는 그보다 훨씬 작다(형성이 동결 의존을 줄임)
- **틀리다면**: q_F ≤ 0.50 ≥ 4/5(손실), q_F ≈ q_D 면 형성이 의존을 줄이지 않음
- **경쟁 가설과 갈리는 지점**: q_F 하나로 남음·손실이 갈리고, q_F − q_D 가 형성 표현의 역할을 가른다
