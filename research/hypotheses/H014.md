# H014: 병목은 출력단이다 — D1 2개로 수렴해 변별이 평균화된다

- **상태**: **활성 (주력, 2026-09-16)**
- **현재 신뢰도**: 중간 (E080에서 측면억제 경로는 기각, 분할 경로는 미검증)
- **경쟁 가설**: H011(전반적 배선), H014-null(출력을 늘려도 무관)

## 진술
KC가 패턴을 잘 구분해도(E079에서 std 4.33 달성) **출력이 D1 좌/우 2개뿐**이라
수천 개 KC의 신호가 **평균화**된다. 출력단 수와 출력 간 경쟁이 병목이다.

## 실측 대조 (FlyWire 783)
| | 실측 | 우리 |
|---|---|---|
| 출력 뉴런 수 | **MBON 96개** | **D1 좌/우 2개** |
| 수렴비 | MBON 1개 ← KC **441개** | D1 1개 ← KC **수천 개** |
| 출력 간 경쟁 | MBON→MBON **억제 50%** | **없음** |
| KC 분산 | KC 1개 → MBON **10개**(p90 13) | KC 1개 → D1 2개 |

## 지지 증거
| 출처 | 관측 | 강도 |
|---|---|---|
| **E079** | 신용 할당을 만들어도(std 4.33) 행동 효과 +0.0005 = 변화 없음 | **강함(소거)** |
| FlyWire | 출력단 96 vs 2, 수렴비 441 vs 수천, 경쟁 50% vs 0 | 강함 |
| C39/C41 | d1 포화(~667 고정) — 극단 수렴의 예상 증상 | 중간 |
| E069/E072 | 가중치·대역폭을 키워도 효과 불변 — 하류가 병목이면 당연 | 중간 |

## 반증 증거
| 출처 | 관측 | 강도 |
|---|---|---|
| — | 출력단을 늘린 적이 **한 번도 없다** | — |

## 예측
- **맞다면**: D1 집단을 좌/우 2개에서 여러 개로 늘리고 **상호 억제**를 넣으면
  d1 포화가 풀리고 (수리−정적) 효과가 커진다.
- **틀리다면**: 출력을 늘려도 효과가 그대로 → 병목이 더 하류(direct/motor) 또는 전반적 배선(H011).

## 다음 판별 실험 (E080, 설계 예정)
1. D1을 **N개 집단**으로 분할(예: 좌/우 각 4~8개), KC→D1 연결을 분산
2. D1 집단 간 **상호 억제** 신설(FlyWire MBON→MBON 억제 50% 근거)
3. 조작 검증: d1 포화가 풀리는가(절대발화 하락), 집단별로 다른 패턴에 반응하는가
4. 그 위에서 반사역전 효과 측정

## E080 결과 (2026-09-16): 측면억제 경로 **기각**, 분할 경로는 남음
좌↔우 교차 억제(−20/−60/−150)로 d1 변별이 커지는지 시험.

| 강도 | 평균 측성차이 | 0 대비 |
|---|---|---|
| 0 | 23.1 | — |
| −20 | 26.9 | 1.16배 |
| −60 | **38.3** | 1.66배 |
| −150 | 10.6 | 0.46배(과억제) |

사전기준(3시드 모두 2배) 미달 → **(a) 기각.** −60에서 seed1만 3.4배로 반응(시드 의존).

**해석**: H014의 진술("병목은 출력단")은 살아 있으나, **경쟁만 넣는 것으로는 부족**하다.
좌↔우 **2개 사이의 경쟁**은 자유도가 너무 낮다 — 두 집단이 서로 누르면 결국 한쪽만 남고
**패턴별로 다른 출력**을 만들 수 없다.

FlyWire는 MBON **96개**가 각자 다른 KC 조합을 받는다(MBON당 441개, KC 1개가 MBON 10개로 분산).
→ **출력 집단 자체를 여러 개로 나누는** 설계가 남은 경로다(E081).
