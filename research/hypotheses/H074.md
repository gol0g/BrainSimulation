# H074: 공통 입력 차단은 같은 학습 크기에서도 상충 과제 B 의 과제 A 자극 전이를 줄인다 — E150 의 유지는 약한 학습만의 산물이 아니다

- **상태**: 활성 — 시험 중 E151(사전등록 2026-10-07, 기준 고정 01:02:17)
- **현재 신뢰도**: 미정 — 근거: E150 사후(탐색적) 전이 T 0.41~0.73(차단, 약한 학습) vs 1.18~1.31(기본 E148). 반대 근거: 두 값은 학습 크기가 4~8배 다른 상태의 비라 연성 상한 비선형이 섞인다
- **경쟁 가설**: H074-mag(학습 크기를 올리면 전이가 기본 수준 — E150 의 낮은 전이는 약한 학습 영역 탓)
- **범위**: 반사 0, 뇌 10~14, 차단(food_eye→KC·좌우 공통 KC 입력 0), KC→motor eta η*(뇌 15 보정), 과제 A 1,500 → 과제 B 1,500

## 진술
공통 입력을 막은 전체 모델에서 KC→motor 학습률을 올려 과제 A·B 학습 크기를 기본 상태에 가깝게 해도, 과제 B 학습 단위당 과제 A 자극의 이동(T)은 기본 상태보다 작다(T ≤ 0.8). 능력 쪽 예측: 과제 A 효과의 절반 이상 유지(rA ≥ 0.5).

## 예측
- **H074(전이 감소)**: eB ≥ +0.15 이고 T ≤ 0.8 ≥4/5
- **H074-mag(기본 수준 전이)**: eB ≥ +0.15 이고 T ≥ 1.0 ≥4/5
- 능력: rA ≥ 0.5 ≥4/5 → 전체 강도 유지 / rA < 0.5 ≥4/5 → 전체 강도 간섭
