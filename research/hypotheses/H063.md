# H063: 보상 창 동안 motor 를 침묵시키면 전체 모델(반사 0) 학습 효과가 커진다

- **상태**: **폐기(시험 못 함)** — E140 경로 검사(뇌 15): 침묵은 듣지만(보상 창 motor 발화율 ≈0.011) 보상 창 흔적 생성이 사라지지 않고 LTD 로 바뀐다. 가설이 기대한 기전(새 post 스파이크를 막으면 가중치 변화가 결정 단계 흔적을 따른다)이 성립하지 않아 본실험을 돌리지 않았다. 질문은 H064(E141, 흔적 생성 동결)로 옮김
- **현재 신뢰도**: 해당 없음(판정 없음)
- **경쟁 가설**: H063-null(침묵해도 같다 — 보상 창 비선택 흔적은 상한 원인이 아님)
- **범위**: E119 반사 0 학습, 뇌 10~14, 침묵 5000(보상 창 2스텝)

## 예측
- 맞다면: 효과 평균 ≤ −0.10, E119 보다 큼 5/5, 선택 KC 의 B/A·C/P 감소
- 틀리면: |e − e_E119| < 0.01 (≥4/5)
