# H064: 보상 창에서 새로 생기는 KC→motor 흔적이 전체 모델(반사 0) 학습 효과의 크기를 제한한다 — 흔적 생성을 멈추면 효과가 커진다

- **상태**: **지지됨** — E141(2026-10-05, 기준 고정 22:19:56): 효과 평균 −0.0772 → −0.2586, 같은 뇌 E119 보다 5/5 커짐(d −0.135~−0.211), 조작검증 4종 5/5, 독립 대조 일치
- **현재 신뢰도**: 높음(범위 안) — 같은 규칙·같은 뇌에서 단일 조작, 조작 도달 정밀 확인(잔차 1.4e-8), 기전 예측(B/A·C/P 음수, ΔD 증가) 5/5
- **경쟁 가설**: H064-null(동결해도 같다) — **기각 쪽**(|d| < 0.01 0/5), H064-rev(작아진다) — **기각 쪽**(d ≥ +0.01 0/5)
- **범위**: 반사 0, 뇌 10~14, 500시행, 보상 창 20스텝, KC→motor 만 동결(D1·피질 경로 그대로), 동결 시점은 호스트가 맞춤

## 진술
보상 창(도파민 켜짐, 20스텝) 동안 KC→motor R-STDP 의 흔적 생성(A_plus·A_minus)을 0으로 두어 흔적이 결정·행동 창 값에서 감쇠만 하게 하면, 가중치 변화가 실행 행동을 따르고(보상: 실행 쪽 ↑·반대쪽 ↓, 처벌: 실행 쪽 ↓·반대쪽 ↑) 선택 KC 의 교차−같은 쪽 차이가 더 빨리 자라, 이식 평가 학습 효과가 E119 보다 커진다(평균 ≤ −0.10).

## 예측
- **맞다면**: e 평균 ≤ −0.10, 같은 뇌 E119 보다 큼 5/5. 기전: B/A < 0·C/P < 0, ΔD 가 E139 보다 큼 → **관측됨**
- **틀리다면(null)**: |e − e_E119| < 0.01 ≥4/5 → 0/5
- **틀리다면(rev)**: e − e_E119 ≥ +0.01 ≥4/5 → 0/5
