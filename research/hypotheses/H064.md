# H064: 보상 창에서 새로 생기는 KC→motor 흔적이 전체 모델(반사 0) 학습 효과의 크기를 제한한다 — 흔적 생성을 멈추면 효과가 커진다

- **상태**: 활성 — 시험 중 E141(사전등록 2026-10-05, 기준 고정 22:19:56)
- **현재 신뢰도**: 낮음~중간 — 근거는 관측뿐: E139(판정 보류) 보상 시행 양쪽 동시 상승·처벌 동시 하락(5/5), E139·E140 경로 검사(뇌 15) 보상 창 끝 흔적이 결정 단계 흔적의 2~4배이고 양쪽 같은 부호
- **경쟁 가설**: H064-null(동결해도 효과가 같다 — 상한은 다른 동역학: 연성 상한·탐색 일정·판독), H064-rev(동결하면 효과가 작아진다 — 보상 창 흔적이 학습에 보탠다)

## 진술
보상 창(도파민 켜짐, 20스텝) 동안 KC→motor R-STDP 의 흔적 생성(A_plus·A_minus)을 0으로 두어 흔적이 결정·행동 창 값에서 감쇠만 하게 하면, 가중치 변화가 실행 행동을 따르고(보상: 실행 쪽 ↑·반대쪽 ↓, 처벌: 실행 쪽 ↓·반대쪽 ↑) 선택 KC 의 교차−같은 쪽 차이가 더 빨리 자라, 이식 평가 학습 효과가 E119 보다 커진다(평균 ≤ −0.10).

## 예측
- **맞다면**: e 평균 ≤ −0.10, 같은 뇌 E119 보다 큼 5/5. 기전: B/A < 0·C/P < 0, ΔD 가 E139 보다 큼
- **틀리다면(null)**: |e − e_E119| < 0.01 ≥4/5 — 가중치 변화 양상은 바뀌어도 행동 효과 크기는 같다
- **틀리다면(rev)**: e − e_E119 ≥ +0.01 ≥4/5
- **경쟁 가설과 갈리는 지점**: 같은 학습 규칙·같은 뇌에서 보상 창 흔적 생성 하나만 끈다. 지지면 상한 원인 = 보상 전달의 시간 구조(규칙의 시간 게이팅), null 이면 상한은 흔적 구성과 무관
