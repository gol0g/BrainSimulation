# H045: 반대 반사(good_food→motor 25)가 없으면 전체 모델의 KC→motor 학습이 정답(교차) 매핑을 행동에 싣는다

- **상태**: 활성 — E119 **보류**(2026-09-28 19:13): 방향 5/5 정답, 크기 사전 기준 미달(1/5)
- **현재 신뢰도**: 중간 — 방향은 강하게 관측(5/5, t≈−10.6), 사전 크기(≤−0.10 4/5)는 미충족. 경쟁 H045-integ(음성 0/5)·H045-common(양수 0/5)은 E119와 맞지 않음. 보상 일정 차이(반사 0: 258~325회 vs 25: 140회) 설명은 미배제
- **경쟁 가설**: H045-integ(통합 자체 — KC 표현 겹침·판독·보상 전달 — 에서 능력을 잃어 반사 없이도 검출 안 됨), H045-common(반사 없이도 공통 상승·같은 쪽 강화가 학습을 지배)

## 진술
E108~E118에서 역전이 검출되지 않은 것은 반사 25의 행동 권한이 학습된 매핑을 덮었기 때문이다. 반사를 0으로 두면(나머지 E118과 같음) 학습이 이식 평가에서 정답 방향 변조폭(≤ −0.10)을 만든다.

## 예측
- **맞다면**: 반사 0 효과(학습 − 무학습 사후 변조폭) ≤ −0.10 뇌 ≥4/5 (뇌 10~14)
- **틀리다면(H045-integ)**: 반사 0 |효과| < 0.03 뇌 ≥4/5
- **H045-common**: 반사 0 효과가 양수(같은 쪽)로 ≥ +0.10
- **경쟁 가설과 갈리는 지점**: 반사 25 칸(같은 뇌, E118 조건 재현)과 짝지어, 반사 유무만 다른 비교에서 학습 효과의 방향·크기가 갈리는가
