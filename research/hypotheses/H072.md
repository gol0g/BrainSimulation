# H072: 전체 모델에서 같은 쪽 good·bad food 자극의 KC 표현은 크게 겹치고, 공통 입력(food_eye·좌우 공통 KC 입력)을 막으면 분리된다

- **상태**: **보류** — E149(2026-10-06 판정): 기본 J 0.37~0.45(문턱 사이 — 중간 겹침), 차단 분리 5/5(J 0.11~0.12, 반응 KC 4~8배 조밀)
- **현재 신뢰도**: 미정 — 근거: K82(상충 과제 B 가 과제 A 를 뒤집음), 배선상 두 자극이 공유하는 KC 입력 = food_eye(같은 쪽)·좌우 공통 피질 입력(IT 등), 자극별 입력 = good_food_eye·bad_food_eye(독립 무작위 연결)
- **경쟁 가설**: H072-low(겹침이 낮다 — 간섭은 표현이 아니라 출력 쪽), H072-nosep(차단해도 겹친다 — 좌우 KC 집단 구조 자체)
- **범위**: 반사 0 뇌 설정, 뇌 10~14, 학습 없는 새 뇌, 자극 4종 × 50제시

## 진술
같은 쪽 good food 와 bad food 자극이 켜는 KC 집합의 자카드는 0.5 이상이고, food_eye→KC 와 좌우 공통 KC 입력을 0으로 하면 0.2 이하로 떨어지면서 자극별 반응 KC 는 기본의 0.2배 이상 남는다.

## 예측
- **겹침 + 분리**: 기본 J ≥ 0.5, 차단 J ≤ 0.2·반응 유지(≥4/5) → E150(차단 상태로 간섭 하 유지)
- **low**: 기본 J ≤ 0.2 ≥4/5
- **nosep**: 기본 J ≥ 0.5, 차단 후에도 분리 안 됨
