# H082: 반사 25 학습 효과 상한은 출력 쪽 효율 저하다

- **상태**: **부분 — E159 판정 둘 다(H082-both) 5/5**: 출력 효율 저하는 있다(O 0.52~0.58 ≤ 0.70) — 그러나 단독 원인이 아니다(학습 내용 C 0.56~0.65 도 ≤ 0.70)
- **현재 신뢰도**: 중간(출력 효율 저하는 확인, 단독 원인은 아님) — 등록 때 근거(탐색, 뇌 10): 반사 0 Fk 500시행 가중치 변화(같은 쪽 −553k·교차 +299k)가 효과 −0.45, 반사 25 Fk 500시행(−301k·+421k)이 −0.30 — 비슷한 변화가 반사 25 에서 덜 듣는 것처럼 보인다. 반대 근거: 두 가중치 집합은 같지 않다(반사 25 는 같은 쪽 감소가 작고 교차 증가가 큼) — 학습 내용 차이도 가능
- **경쟁 가설**: H082-content(학습 내용), H082-both(둘 다), H082-neither(둘 다 아님)
- **범위**: 뇌 10~14, 이득 맞춘 형성 표현(×0.70), 500시행 학습 가중치, 학습 없는 분해 평가

## 진술
같은 학습 가중치(반사 0 에서 배운 것)를 반사 25 뇌에 이식하면 효과가 반사 0 평가의 70% 이하로 준다.

## 예측
- **출력**: O ≤ 0.70·C > 0.70 뇌 ≥ 4/5
- **내용**: O > 0.70·C ≤ 0.70 ≥ 4/5
- **둘 다**: O, C ≤ 0.70 ≥ 4/5 / **둘 다 아님**: O, C > 0.70 ≥ 4/5
