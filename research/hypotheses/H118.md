# H118: 현재 C2 KC 표현은 부호 판독(반응 KC 전부를 SXI 부호 쪽으로 300/0)이면 L4 를 행동으로 표현할 수 있다

- **현재 신뢰도**: 낮음~중간 — 등록 때 근거: E196 에서 XOR 선택 KC 이상값(sel)으로도 네 칸 20/20 정답 방향(+0.083 평균, K127); 사후 추정(탐색)으로 부호 판독의 XOR 차분 구동이 sel·eq 의 2.5~3배(범주 구동의 약 2/3), 선형 근사로 뇌마다 칸 평균 0.17~0.26. 반대 근거: 큰 구동에서 압축(범주 팔 과대예측), 칸 불균형 예측(뇌 14 최소 칸 0.03), 약한 선택 KC 의 부호가 평가 창에서 재현되는지 미확인.
