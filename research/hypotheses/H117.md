# H117: 현재 C2 KC 표현과 KC→motor 경로는 L4 를 행동으로 표현할 수 있다 — XOR 선택 KC 의 이상 가중치로 네 칸이 선다

- **상태**: 등록(E196 — 2026-10-15)
- **현재 신뢰도**: 중간 — 등록 때 근거: KC 에서 XOR 이 98~100% 선형으로 읽히고(K123, C2), 반응 KC 중 |SXI| ≥ 0.5 가 두 쪽 합 153~196(쪽마다 75~102 — E195 S1 판정 수; K74 의 좌우 선택 KC 집단당 131~164 의 약 0.5~0.8배 — 선택 지표는 다름); 단순 좌우 규칙에서는 선택 KC 이상 가중치의 권한이 학습 효과의 5~8배였다(K74). 반대 근거: XOR 선택 KC 는 칸마다 그 일부만 반응한다(교차 선택 KC 의 대략 절반이 X·A, 나머지가 Y·B) — 칸당 구동이 좌우 규칙보다 작을 수 있다; 반응 KC 활동 가중 순도는 약 0.1(K126); 양성 대조 cat 의 선택 KC(쪽마다 197~227)는 sel(76~102)의 2.2~2.9배(E192 C2 로그 사전 확인).
- **경쟁 가설**: H117-null(표현·출력 병목 — 이상 가중치로도 획득 칸 ≤ 1), 부분(2~3 칸)
- **범위**: 뇌 10~14, C2(w 20·p 0.02), 형성 전 특징 표현, motor 기저값 −4900, 이식 평가만(학습 없음), KC→motor 4집단만 설계(D1 초기값), θ 0.5·300/0

## 진술
O_sel(반응·SXI ≥ 0.5 → 교차 300·같은 쪽 0, ≤ −0.5 → 반대, 나머지 150)에서 E193 과 같은 판정의 네 칸 a_train ≥ 0.10 — 4/5 뇌(양성 대조 O_cat 통과 4/5 전제). 부 진술: O_eq(SXI 비례 상관 판독)도 네 칸 — 서면 학습 동역학 병목, 안 서면 학습 규칙(상관 평형) 병목.

## 예측
- **H117(표현 충분)**: sel 획득 ≥ 4/5 → eq 에 따라 동역학/규칙 병목
- **H117-null(표현·출력 병목)**: sel 획득 칸 ≤ 1 ≥ 4/5
- **부분**: sel 2~3 칸 ≥ 4/5
