# H075: 기본 표현의 good·bad KC 겹침은 공통 입력 단독 구동에서 온다 — 겹침 KC 대부분이 먹이 단독 자극에도 반응한다

- **상태**: **반증(H075-conj 지지)** — E152(2026-10-07 판정, 수정 1 기준): 겹침 KC 의 먹이 단독 반응 몫 φ 0.02~0.06(5/5 ≤ 0.3). 원래 기준은 측정 검증 M2 0/5 로 보류
- **현재 신뢰도**: 낮음(반증) — 먹이 입력만으로는 KC 가 거의 켜지지 않고(쪽당 0~7개), 겹침은 공통 + 종류 입력 결합에서 온다(K86)
- **경쟁 가설**: H075-conj(겹침 KC 대부분은 먹이 단독에 반응 안 함 — 공통 + 종류 결합)
- **범위**: 반사 0 뇌 설정, 뇌 10~14, 학습 없음, 문턱 0.5

## 진술
같은 쪽 good·bad 자극 둘 다에 반응하는 KC 중 70% 이상이 먹이 단독(food 광선만) 자극에도 반응한다.

## 예측
- **먹이 주도(H075)**: φ ≥ 0.7 ≥4/5
- **결합 주도(H075-conj)**: φ ≤ 0.3 ≥4/5
- 그 밖 혼합
