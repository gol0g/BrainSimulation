# H084: 망 안 Oja 형성은 쓰지 않은 뇌에서도 분리와 학습 이점을 재현한다

- **상태**: **지지 — E161 형성 성공 5/5**(쓰지 않은 뇌 16~20, 자카드 ≤ 0.018·r 2.09~2.36)
- **현재 신뢰도**: 높음(범위 안 — 쓰지 않은 뇌 확증) — 이전: 근거: E160 개발 자료(뇌 10~14) 자카드 ≤ 0.027·r 2.19~2.58(5/5, 사전 판정은 MS 4/5 로 보류). 반대 근거: η·β 는 뇌 15 격자에서 조건을 만족한 유일한 칸(오른쪽 선택성 0.800 경계) — 새 뇌에서 선택성이 낮을 수 있다
- **경쟁 가설**: H084-sep-only(분리만), H084-null(분리 안 됨)
- **범위**: 뇌 16~20, η 0.02·β 0.3·m_max 32·τ 20·노출 100, 반사 0·500시행

## 진술
망 안 Oja 형성 가중치를 실은 뇌 16~20 에서 자카드 ≤ 0.10(양쪽)이고 500시행 학습 효과가 같은 뇌 기본의 1.30배 이상이다(≥4/5).

## 예측
