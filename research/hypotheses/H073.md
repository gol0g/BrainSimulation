# H073: 전체 모델의 간섭(K82)은 공통 입력이 만드는 good·bad KC 표현 겹침에서 온다 — 공통 입력을 막으면 간섭 하 유지가 회복된다

- **상태**: 활성 — 시험 중 E150(사전등록 2026-10-06, 기준 고정 21:44:57)
- **현재 신뢰도**: 미정 — 근거: K83(중간 겹침 0.37~0.45, 차단으로 0.11~0.12). 반대 근거: 차단 시 KC 반응이 4~8배 조밀해져 일반화·간섭이 오히려 커질 수 있다; 간섭이 출력 쪽(motor·D1)에서 올 수도 있다
- **경쟁 가설**: H073-null(차단해도 간섭 — 겹침 아닌 다른 원인)
- **범위**: 반사 0, 뇌 10~14, 차단(food_eye→KC·좌우 공통 KC 입력 0), 과제 A 1,500 → 과제 B 1,500

## 진술
공통 입력을 막은 전체 모델은 과제 A(good → 교차)를 익힌 뒤 상충 과제 B(bad → 같은 쪽)를 배워도, 과제 A 효과를 같은 차단 상태의 과제 A 단독 효과의 절반 이상 유지한다.

## 예측
- **유지**: rA ≥ 0.5 ≥4/5 (전제: 차단 상태 과제 A·B 학습)
- **간섭 유지**: rA < 0.5 ≥4/5
