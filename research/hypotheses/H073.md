# H073: 전체 모델의 간섭(K82)은 공통 입력이 만드는 good·bad KC 표현 겹침에서 온다 — 공통 입력을 막으면 간섭 하 유지가 회복된다

- **상태**: **지지(사전 기준) — 교란 범위 안** — E150(2026-10-07 판정): 차단 상태 유지 몫 0.61~0.64(5/5), 조작검증 10/10, 전제 P1 5/5·P2 4/5, 독립 대조 일치
- **현재 신뢰도**: 중간 — 관측(차단하면 간섭이 크게 준다)은 강하다. 원인이 '겹침 감소'라는 해석은 교란 둘을 못 가른다: ① 차단 상태 학습이 약하다(과제 A 효과 기본의 약 1/4, 과제 B 1/4~1/8 — 작은 과제 B 변화가 덜 덮어썼을 수 있음), ② KC 반응 4~8배 조밀(E149, 사전 명시). 사후(탐색적): 과제 B 단위당 과제 A 자극 이동 T 0.41~0.73 vs 기본 1.18~1.31 — ① 만으로는 다 설명 안 되는 쪽이나 학습 크기가 달라 결정적이지 않다
- **경쟁 가설**: H073-null(차단해도 간섭 — 겹침 아닌 다른 원인) — E150 에서 0/5
- **범위**: 반사 0, 뇌 10~14, 차단(food_eye→KC·좌우 공통 KC 입력 0), 과제 A 1,500 → 과제 B 1,500, eta 0.15

## 진술
공통 입력을 막은 전체 모델은 과제 A(good → 교차)를 익힌 뒤 상충 과제 B(bad → 같은 쪽)를 배워도, 과제 A 효과를 같은 차단 상태의 과제 A 단독 효과의 절반 이상 유지한다.

## 예측
- **유지**: rA ≥ 0.5 ≥4/5 (전제: 차단 상태 과제 A·B 학습)
- **간섭 유지**: rA < 0.5 ≥4/5
