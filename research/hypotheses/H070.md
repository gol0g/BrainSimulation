# H070: 반사 0·K75 동결 전체 모델은 익힌 교차 규칙을 뒤집어 다시 배운다 — 최소 회로 반전 능력(K48)의 보존

- **상태**: 활성 — 시험 중 E147(사전등록 2026-10-06, 기준 고정 17:23:03)
- **현재 신뢰도**: 미정 — 근거: K75·K80(동결 하 학습이 크고 학습량에 따라 자람), 연성 상한 아래 반전 방향 여유가 큼(교차 높음 → 깎을 여유, 같은 쪽 낮음 → 올릴 여유). 반대 근거: 최소 회로 반전은 느렸다(K48 — 획득 400 뒤 475~704시행), 1,500시행 끝에 차이 성장 정체(K80)
- **경쟁 가설**: H070-partial(반전 쪽으로 움직이나 1,500시행 안에 못 넘음), H070-stuck(반전 쪽 이동 < 0.05 — 고착)
- **범위**: 반사 0, 뇌 10~14, 교차 1,500 + 반전 1,500시행, 좌우 규칙

## 진술
교차 규칙을 1,500시행 익힌 전체 모델에서 보상 규칙을 같은 쪽으로 바꾸면, 1,500시행 안에 이식 평가 변조폭이 같은 쪽(≥ +0.02)으로 넘어간다.

## 예측
- **성공**: 사후 ≥ +0.02 ≥4/5
- **부분**: 사후 − 반전 직전 기준 ≥ +0.10 5/5, 사후 < +0.02
- **고착**: 사후 − 기준 < +0.05 ≥4/5
