# H065: 보상 창 흔적 동결(K75) 하에서 KC→motor 학습은 선천 반사 25 를 이긴다(헌장 L2)

- **상태**: **부분(H065-partial)** — E142(2026-10-06 판정): 동결 하 학습은 반사 25 를 크게 거스르지만(500시행 −0.27, 무동결 ≈0) 1,500시행에도 넘지 못한다(사후 +0.08~+0.13, L2 0/5)
- **현재 신뢰도**: 원 진술(1,500시행 L2)은 반증 쪽, '거스른다'는 강함 — 남은 반사 우세의 출처는 탐색적 분해상 결정 단계 비선택 흔적 × 연성 상한의 내부 평형(E143 에서 시험)
- **경쟁 가설**: H065-partial(학습이 반사를 거스르지만 1,500시행 안에 못 넘는다 — 권한·시간 한계), H065-null(반사 조건에는 동결로 풀리지 않는 다른 장애가 있다 — 500시행 효과 ≈0)
- **범위**: 반사 25(E119 와 같은 반사 가중치), 뇌 10~14, 500·1,500시행, 동결은 KC→motor·보상 창(도파민 구간)만

## 진술
보상 창(도파민 켜짐) 동안 KC→motor 흔적 생성을 끄면, 반사 25 가 있어도 가중치 변화가 실행 행동을 따른다 — 반사 쪽 실행의 처벌이 같은 쪽을 깎고 교차를 올리고, 탐색 정답의 보상이 교차를 올린다. 그 결과 학습이 반사를 거스르고(500시행 효과 ≤ −0.10), 1,500시행이면 이식 평가 사후 변조폭이 교차 쪽(≤ −0.02)으로 넘어간다.

## 예측
- **맞다면(L2)**: F1500 사후 변조폭 ≤ −0.02 ≥4/5
- **부분이면**: F500 효과 ≤ −0.10 5/5, F1500 사후는 여전히 반사 쪽
- **틀리다면(null)**: F500 |효과| < 0.03 ≥4/5(E119 무동결과 같음)
- **경쟁 가설과 갈리는 지점**: E119 반사 25(무동결, 같은 뇌·같은 시행 난수열)와 동결 하나만 다른 F500 짝이 동결의 효과를, F1500 의 사후 부호가 L2 를 가른다. NF1500(무동결 1,500시행, 수정 1)과 F1500 의 짝이 L2 에서 동결의 필요성을 가른다
