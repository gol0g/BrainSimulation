# H076: 경험 형성(종류 입력 합 보존 헤브 재분배)으로 권한을 잃지 않는 good·bad KC 분리를 만들 수 있다

- **상태**: 활성 — 시험 중 E153(사전등록 2026-10-07, 기준 고정 19:25:45)
- **현재 신뢰도**: 미정 — 근거: 겹침은 공통 + 종류 입력 결합에서 오고 먹이 입력만으로는 KC 가 거의 안 켜진다(K86) — 각 KC 의 종류 입력을 한쪽으로 모으면 다른 종류에는 문턱 아래가 될 것. 최소 회로에서 같은 종류의 형성 규칙(K69)이 관계 특징을 만들었다. 반대 근거: 종류가 켜는 좌우 공통 피질 입력이 겹침에 기여하면 직접 입력 재분배로는 부족; 재분배가 반응 크기를 바꿔 권한을 잃을 수 있다
- **경쟁 가설**: H076-null(분리 실패), H076-auth(권한 상실)
- **범위**: 반사 0, 뇌 10~14, 노출 100회 × 4, η 0.1(보정 규칙), 호스트 적용

## 진술
보상 없는 노출에서 각 KC 의 종류 입력을 그 KC 의 발화에 따라 한 종류로 모으면(KC 별 합 보존), 같은 쪽 good·bad 자카드가 0.25 이하가 되고 과제 A 500시행 학습 효과가 같은 뇌 기본의 2/3 이상이다.

## 예측
- **형성 성공(H076)**: 분리(두 쪽 J ≤ 0.25)·권한(3·e ≤ 2·e_E141) 둘 다 ≥4/5
- **분리 실패(H076-null)**: 분리 아님 ≥4/5
- **권한 상실(H076-auth)**: 분리이나 권한 아님 ≥4/5
