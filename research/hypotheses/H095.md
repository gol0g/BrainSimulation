# H095: 망 안 형성 표현의 간섭 하 유지(K95)는 설정 선택에 쓰지 않은 뇌에서도 성립한다(독립 확증)

- **상태**: **지지 — E172 유지 5/5**(rA 0.97~0.99, T 0.01~0.03; 크기 부판정 rA ≥ 0.80 5/5; 독립 대조 일치) — K95 독립 확증
- **현재 신뢰도**: 높음(확증 — 뇌 16~20, 범위: env seed 0 시행 난수열 하나·1,500 + 1,500시행·동결 하). 등록 때 근거: 뇌 10~14 에서 rA 0.95~1.00·T 0.00~0.05(E162, 5/5), 형성 자체는 뇌 16~20 에서 확증(K94 — 자카드 ≤ 0.018, 500시행 학습 이점 2.09~2.36배), 같은 뇌의 노출 통계 변형에도 견고(K98). 반대 근거: 유지·반전 설계(과제 길이 1,500 + 1,500, 문턱)는 뇌 10~14 의 E148·E154·E162 결과를 보며 정했다 — 개발 뇌 결과가 그 뇌에 맞춰졌을 수 있다
- **경쟁 가설**: H095-null(간섭 — 새 뇌에서는 과제 B 가 과제 A 를 지운다)
- **범위**: 뇌 16~20, 반사 0·보상 창 동결, 과제 A 1,500 → 과제 B 1,500, E161 망 안 형성 가중치(η 0.02·β 0.3 고정)

## 진술
설정 선택에 쓰지 않은 뇌 16~20 에서, 망 안 형성 표현을 실은 전체 모델은 과제 B(bad → 같은 쪽) 1,500시행 뒤에도 과제 A(good → 교차) 효과의 유지 몫 rA ≥ 0.5 를 지킨다(≥ 4/5) — E162 규칙 그대로.

## 예측
- **유지(확증)**: rA ≥ 0.5 ≥ 4/5(전제 P1 eA1 ≤ −0.20·P2 eB ≥ +0.15 ≥ 4/5)
- **간섭**: rA < 0.5 ≥ 4/5
- **부판정(크기 서술)**: rA ≥ 0.80 ≥ 4/5 이면 K95 의 크기 서술(95~100%)까지 확증 범위, 아니면 크기 서술은 개발 뇌 한정
