# H102: 반사 25 출력 효율 저하(K92 의 O 0.52~0.58)는 motor 동작점 포화 때문 — 기저값 −4000 에서 O ≥ 0.85

- **상태**: 활성 — E181 에서 시험(평가만, 뇌 10~14)
- **현재 신뢰도**: 미정 — 근거: E180·E178 에서 동작점을 내리면 같은 가중치의 단독 효과가 2.0~2.4배로 표현됨(상한 근처 압축), 반사 25 는 반사 쪽 motor 를 강하게 구동해 동작점을 상한 쪽으로 민다(추론). 반대 근거: 조합 비가산은 동작점 탓이 아니었다(K112) — 반사 경로와 학습 경로의 motor 수준 경쟁이 같은 꼴일 수 있다
- **경쟁 가설**: H102-null(손실 유지 — O ≤ 0.70)
- **범위**: 뇌 10~14, 이득 맞춘 형성 표현(E153 ×0.70), W0(E157 반사 0 500시행)·W25(E158 반사 25 500시행), 평가 반사 0·25, motor 기저값 −4000

## 진술
E159 교차 평가를 motor 기저값 −4000 에서 다시 재면 반사 0 학습 가중치의 반사 25 효율 O = E(W0,R25)/E(W0,R0) ≥ 0.85 (≥ 4/5).

## 예측
- **회복**: O ≥ 0.85 ≥ 4/5
- **손실 유지**: O ≤ 0.70 ≥ 4/5
- **판정 2(L2 지표)**: v(W25, R25) ≤ −0.02 ≥ 4/5 — 기존 반사 25 학습 가중치가 새 동작점에서 반사를 뒤집음
