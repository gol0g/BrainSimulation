# H077: 경험 형성 표현(E153)을 실은 전체 모델은 전체 강도에서 상충 연합을 함께 담는다 — 최소 회로 K51 의 전체 모델 보존

- **상태**: 등록 — E154(사전등록 2026-10-07, 기준 고정 19:37:46). E153 = 형성 성공(H076)일 때만 시험
- **현재 신뢰도**: 미정 — 근거: 간섭은 공통 입력이 만드는 겹침에 달려 있고(K84), 겹침은 공통 + 종류 결합에서 온다(K86); 형성 표현은 겹침을 없앤다(E153 경로 검사 뇌 15 J 0.00). 반대 근거: 출력 쪽(motor·D1)이나 좌우 공통 피질 경로가 과제 A·B 를 잇는다면 표현을 갈라도 간섭이 남는다
- **경쟁 가설**: H077-null(KC 표현을 갈라도 간섭)
- **범위**: 반사 0, 뇌 10~14, 형성 표현(E153), eta 0.15, 1,500 + 1,500시행

## 진술
형성 표현을 실은 전체 모델이 과제 A(good → 교차)를 1,500시행 익힌 뒤 상충 과제 B(bad → 같은 쪽)를 1,500시행 익혀도, 과제 A 효과를 같은 형성 표현의 과제 A 단독 효과의 절반 이상 유지한다.

## 예측

- **간섭**: rA < 0.5 ≥4/5
