# H012: KC 경로가 학습에 참여하지 않는 이유는 도파민이 KC에 도달하지 않기 때문이다

- **상태**: **기각됨** (측정, 2026-09-16)
- **현재 신뢰도**: 없음 (기각)
- **경쟁 가설**: H012-null(도파민을 줘도 KC는 학습하지 않는다), H011(전반적 배선 문제)

## 진술
우리 뇌는 초파리 버섯체를 본떠 KC 층을 만들었으나, **도파민이 D1에만 주입되고 KC에는
전혀 도달하지 않는다.** 실제 초파리는 DAN이 KC에 **39,362개 연결**로 직접 투사해
KC→MBON 시냅스를 변조하며, **이것이 MB 학습이 일어나는 지점**이다.

## 지지 증거
| 출처 | 관측 | 강도 |
|---|---|---|
| **FlyWire 실측** | DAN→KC 연결 **39,362개** / 시냅스 50,654 | **강함** |
| **C30 가소성 감사** | `kc_to_d1_l/r`, `kc_to_d1ctx_*` 전부 **변화 없음** 목록 | 강함 |
| 코드 확인 | `release_dopamine`이 D1·R-STDP 시냅스에만 작용, KC 경로는 대상 아님 | 강함 |

## 예측
- **맞다면**: KC 경로를 도파민 게이팅 R-STDP로 바꾸면 `kc_to_d1*`의 가중치가 **시냅스별로 분화**한다
  (std 0 → 증가). C36에서 `food_to_d1`이 그랬던 것과 같은 서명.
- **틀리다면**: 도파민을 줘도 KC 가중치가 안 변한다 → 다른 이유(KC 발화 패턴 등).

## 반증 증거
| 출처 | 관측 | 강도 |
|---|---|---|
| — | 아직 없음. KC에 도파민을 준 적이 **한 번도 없다** | — |

## 왜 중요한가
초파리 MB는 **스파스 코딩으로 패턴을 분리**하는 구조다(우리가 차용한 이유).
그 층이 학습에 참여하지 않으면 **변별 학습의 핵심 기구가 놀고 있는 것**이다.
CHARTER의 개념 조건 중 **일반화**와 직결된다.

## 다음 판별 실험 (E079, 설계 예정)
1. `kc_to_d1_l/r`을 **진짜 R-STDP**(시냅스별 자격흔적 + 도파민 게이팅)로 교체
   — `rstdp_model.py`가 이미 있으므로 배선만 하면 된다
2. 조작 검증: 도파민 OFF에서 |Δ|=0, ON에서 std 0→증가 (C36과 동일 방식)
3. 그 위에서 반사역전 과제 효과를 잰다

## ★검증 착수 중 발견 — 이 가설의 전제가 흔들린다 (2026-09-16)
배선 작업 중 코드를 보니, **`_update_rstdp_weights()` 안에 KC 학습 블록이 이미 존재**한다
(forager_brain.py 5459행, "Phase L16: KC → D1/D2"). 그리고 게이트 조건이 전부 참이다:
- `sparse_expansion_enabled = True`
- `hasattr(kc_to_d1_l) = True`
- `_skip_blind = _context_hard_gate_active = False`

즉 **"도파민이 KC에 도달하지 않는다"는 진술이 코드 수준에서 맞지 않을 수 있다.**
그런데도 C30에서 `kc_to_d1*`이 "변화 없음"이었다 → 막히는 지점이 다른 데 있다.

**결론 전에 측정한다**(조작 무효를 5회 겪은 프로젝트다):
`kc_learning_probe.py` — 게이트 조건 / KC 발화 여부 / 보상 100회 후 가중치 변화 /
`_update_rstdp_weights` 반환값에 KC 항목이 있는지.

가능한 시나리오:
1. KC가 **발화하지 않는다** → pre 활동이 없어 학습 조건 미충족
2. 학습 블록이 **실행되지만 변화량이 0에 수렴**(eta 0.0003으로 매우 작음)
3. 다른 조건(`perceptual_learning_enabled` 등)에서 막힌다
4. C30 측정 자체의 문제(그때는 `decay_dopamine`을 호출했으나 다른 경로였을 수 있음)

**어느 쪽이든 H012의 진술을 수정해야 한다.**

## 기각 (kc_learning_probe.py, 2026-09-16)
**진술이 틀렸다. 도파민은 KC에 도달하고 KC는 학습하고 있다.**

| 측정 | 결과 |
|---|---|
| 게이트 조건 | 전부 참 (`sparse_expansion_enabled`, `hasattr(kc_to_d1_l)`, `_skip_blind=False`) |
| KC 발화 | kc_left **299** / kc_right **79** 스파이크 (pre 활동 정상) |
| 보상 100회 후 `kc_to_d1_l` | **|Δ|=0.0299, 변화율 100%** ← 실제로 변함 |
| `_update_rstdp_weights` 반환값 | KC 항목 **4개 존재**(`kc_d1_l`, `kc_d2_l`, `kc_d1_r`, `kc_d2_r`) |

→ "도파민 미도달"은 **명백히 틀렸다.** FlyWire 실측(DAN→KC 39,362연결)에서 구조적 유사성을
   추론했으나, **우리 코드를 측정하지 않고 가설을 세운 것**이 잘못이었다.

## 그러나 진짜 문제를 찾았다 → **H013**
`std(후) = 0.0000` — **모든 시냅스가 똑같이 변한다.**
갱신식(forager_brain.py 5509행): `w_d1 += eta_d1 * d1_trace * self.dopamine_level`
`d1_trace`는 **집단 전체의 스칼라 하나**다. C35에서 찾은 피질 학습(`w[:] += eta*trace`)과 동일 구조.

**KC 학습은 작동하지만 신용 할당이 없다.** 스파스 코딩으로 패턴을 분리해놓고
그 분리를 학습에 쓰지 못한다. → H013으로 이어감.
