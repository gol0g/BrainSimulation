# H110: 원시 특징 범주 체계도 간섭 하 유지를 보존한다 — 특징을 공유하며 반대 규칙을 요구하는 둘째 범주 쌍을 배워도 첫 쌍 규칙이 남는다

- **상태**: **기각(이 범위)** — E189(2026-10-13): 간섭 5/5(둘째 쌍 획득 5/5 위에서 유지 몫 r_A 0.17~0.39·r_B 0.04~0.25), 독립 대조 같음
- **현재 신뢰도**: 낮음(형성 전 원시 특징 표현 범위) — 첫 쌍은 뒤집히지 않고 기준의 4~39% 로 줄었다. 등록 때 근거: 설계 채널 형성 표현에서 간섭 하 유지 0.95~1.00(K95, 독립 확증 0.97~0.99), 최소 회로 유지(K51). 반대 근거: 원시 특징 범주는 형성 전 KC 집합이 0.24~0.42 겹치고(K114) 둘째 쌍이 원형 단위를 공유해 공유 KC 가 상충 갱신을 받는다; 기본 표현에서는 상충 과제가 옛 과제를 뒤집었다(K82).
- **경쟁 가설**: H110-null(간섭 — 유지 몫 < 0.5), 전제 미달(둘째 쌍 미획득)
- **범위**: 뇌 10~14, 둘째 쌍 1,500, 공유 단위 10, 한 사례 세계, 기저값 0

## 진술
둘째 쌍 획득(e_C,train ≥ +0.10·e_D,train ≤ −0.10) 위에서 첫 쌍 유지 몫 r_A = e_A,train/R_A,train·r_B = e_B,train/R_B,train(R = E184 U, 같은 뇌) 둘 다 ≥ 0.5 — 4/5.

## 예측
- **유지**: 위 조건(완전 유지 r ≥ 0.8 은 보고)
- **간섭**: 한 범주라도 r < 0.5(공유 단위 쪽 범주가 먼저 무너질 것)
- **전제 미달**: 둘째 쌍 획득 < 4/5 → 판정 보류
