# H096: 망 안 형성 표현의 규칙 반전(K96)은 설정 선택에 쓰지 않은 뇌에서도 성립한다(독립 확증)

- **상태**: 활성 — 시험 중 E172(사전등록 2026-10-10)
- **현재 신뢰도**: 미정 — 근거: 뇌 10~14 에서 반전 사후 +0.62~+0.66·Δ +1.23~+1.30(E163, 5/5), 기본 표현(E147 K81)·호스트 형성(E155)에서도 반전 성공, 형성은 뇌 16~20 에서 확증(K94). 반대 근거: 반전 설계(1,500 + 1,500)와 문턱은 뇌 10~14 결과(E147·E155)를 보며 정했다
- **경쟁 가설**: H096-null(고착 — Δ < +0.05 ≥ 4/5), H096-partial(부분)
- **범위**: 뇌 16~20, 반사 0·보상 창 동결, 교차 1,500 → 같은 쪽 1,500, E161 망 안 형성 가중치

## 진술
설정 선택에 쓰지 않은 뇌 16~20 에서, 망 안 형성 표현을 실은 전체 모델은 교차 규칙 1,500시행 뒤 규칙이 바뀌면 1,500시행 안에 반전 쪽(사후 m ≥ +0.02)으로 다시 배운다(≥ 4/5) — E163 규칙 그대로(반전 직전 기준 = 같은 뇌 E172 A단독 사후).

## 예측
- **반전 성공(확증)**: m ≥ +0.02 ≥ 4/5
- **부분**: 성공 아님·Δ ≥ +0.10 5/5 / **고착**: Δ < +0.05 ≥ 4/5
- **부판정(크기 서술)**: m ≥ 0.8·|R| ≥ 4/5 이면 K96 의 '거울상 크기' 서술까지 확증 범위, 아니면 크기 서술은 개발 뇌 한정
