# H104: 범주 표지 없는 감각 특징 채널에서 망 안 Oja 가 경험으로 범주 선택 KC 를 만들고, 새 사례도 자기 범주로 분리된다

- **상태**: 활성 — E183 에서 시험(계획: 뇌 15 보정 → 뇌 10~14, 측정만)
- **현재 신뢰도**: 미정 — 근거: 미리 나뉜 good·bad 채널에서는 망 안 Oja 가 종류 선택성을 0.55 → 0.75~0.94 로 올렸다(K93·K94, 노출 통계에 견고 K98). 최소 회로에서 Oja 형 경쟁 가소성이 경험 상관에서 비교 특징 편향을 만들었다(K72). 반대 근거: 지금까지의 '형성'은 이미 나뉜 두 채널 중 고르기였다 — 한 채널 안 특징 분포에서 범주 경계를 만드는 것은 시험한 적 없음. KC 승자 선택형 억제 고리가 입력 변화를 상쇄한 전례(K105·K106).
- **경쟁 가설**: H104-null-1(무작위 투영만으로 같은 분리 — 형성 이득 없음), H104-null-2(노출 사례 암기 — 새 사례 이득 없음), H104-null-3(한 범주로 붕괴)
- **범위**: 전체 모델(28,323뉴런 + 새 특징 집단 feat_l·feat_r 각 200), 초기 연결 스냅숏, 반사 0, good·bad 눈 전류 0, 원형 A·B(40 활성·공유 10) 왜곡 사례(12 교체), 노출 범주당 6 사례

## 진술
보상 없는 노출 뒤 새 사례 x 의 J(K(x), K_자기) − J(K(x), K_다른) 이 같은 뇌·같은 사례의 형성 전보다 최소 의미 효과 이상 크다 ≥ 4/5, 새 사례 이득/노출 사례 이득 ≥ 0.5.

## 예측
- **지지**: 위 조건 — 형성이 범주 경계를 만들고 새 사례로 일반화
- **null-1**: 이득 < 최소 의미 효과 ≥ 4/5
- **null-2**: 노출 사례만 이득(비 < 0.5) ≥ 4/5
- **null-3**: 범주 집합 자카드 ≥ 0.8
