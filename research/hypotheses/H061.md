# H061: 전체 모델(반사 0) KC→motor 학습 효과의 크기 한계는 표현(선택 KC 권한)에서 오는가, 학습 동역학에서 오는가 — 그리고 비선택 KC 의 공통 구동이 효과를 누르는가

- **상태**: 시험 중 — E138(사전등록 2026-10-02, 기준 고정 23:20:08·23:20:43 수정)
- **현재 신뢰도**: 미정 — 근거 없음. 배경: 효과 0.061~0.103 은 판독 권한 R≈0.55 의 약 14%(K57), 학습량 3배에도 그대로(K58), 좌우 공통 KC 입력 제거로 안 바뀜(K59), E117 의 "공유 KC 1.7~2.9배"는 ≥1 스파이크 기준(자발·지속 발화로 부풀 수 있음)
- **하위 가설**: H061-rep(표현 상한, ρ = R_sel/|e| ≤ 2.5) vs H061-learn(학습 상한, ρ ≥ 4) / H061-cm(공통 모드 억제, κ ≥ 1.5) vs 억제 없음(κ ≤ 1.1)
- **범위**: E119 반사 0 학습 가중치(뇌 10~14), 이식 평가, 발화 수 기준 선택성(SI 문턱 0.5)

## 예측
- H061-rep 이 맞다면: 선택 KC 만 교차 연결한 권한 R_sel 이 학습 효과의 2.5배 이하 — 학습이 이미 선택 KC 몫을 거의 다 썼다 → 다음은 선택성을 늘리는 표현 조작
- H061-learn 이 맞다면: R_sel 이 학습 효과의 4배 이상 — 다음은 학습 쪽 조작
- H061-cm 이 맞다면: 비선택 KC 를 초기값으로 되돌린 이식에서 효과가 1.5배 이상
