# H105: 원시 특징 범주 의존 규칙(A → 교차, B → 같은 쪽)을 섞어 배운 전체 모델은 훈련에 없던 새 사례에도 규칙을 적용한다

- **상태**: 활성 — E184 에서 시험(주 팔 형성 전 U, 뇌 10~14)
- **현재 신뢰도**: 미정 — 근거: KC 수준에서 새 사례도 자기 범주 집합과 더 겹친다(K114, S 0.17~0.19); 규칙 수준 변형 일반화(K80)·설계 채널 상충 연합(K95)은 섰다. 반대 근거: 같은 자극 자리에서 반대 규칙을 섞어 배우는 쌍조건은 같은 쪽 규칙이 약했다(K111) — 범주 공통 KC(형성 전 J_AB 0.24~0.42)가 공유 경쟁을 만들 수 있다.
- **경쟁 가설**: H105-null(사례 한정), 한 범주만, 획득 실패
- **범위**: 뇌 10~14, 한 사례 세계(시드 18300), 1,500시행, 반사 0, 기저값 0, 특징 w 24(형성 전)

## 진술
획득(e_A,train ≤ −0.10·e_B,train ≥ +0.10)·일반화(e_A,new ≤ −0.05·e_B,new ≥ +0.05·새/훈련 비 ≥ 0.5) ≥ 4/5.

## 예측
- **지지(개념 수준)**: 위 조건 ≥ 4/5
- **사례 한정**: 획득 ≥ 4/5, 일반화 실패
- **한 범주만**: 쌍조건처럼 한 규칙만
