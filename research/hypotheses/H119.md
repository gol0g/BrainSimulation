# H119: E193 L4 학습 가중치의 방향(KC 마다 교차 − 같은 쪽 학습 차의 부호)은 L4 를 행동으로 낼 만큼 맞다 — 학습의 부족은 크기(등급 평형)다

- **상태**: 등록(E198 — 2026-10-16)
- **현재 신뢰도**: 낮음~중간 — 등록 때 근거: E193 학습 효과는 20/20 칸 정답 방향(K124 — 크기만 작음), 부호 판독은 측정 지수로 L4 획득 4/5(K128); 학습 기울기는 결합 KC 에서 정답 방향(K125 탐색 — 순도 비례로 작음). 반대 근거: 비선택·약한 선택 KC 의 학습 차는 잡음 크기일 수 있다 — 부호 판독은 약한 선택 KC 까지 부호대로 쓰므로 부호가 틀린 KC 가 많으면 효과가 상쇄된다.
- **경쟁 가설**: H119-null(학습 방향 부족 — lsgnR 획득 칸 ≤ 1: 신용 할당도 병목), 부분(2~3 칸)
- **범위**: 뇌 10~14, E193 학습(C2·기저값 −4900·3,000시행) 가중치, E196 −4900 측정 반응 KC, 이식 평가만(학습 없음), KC→motor 4집단만 설계(D1 초기값)

## 진술
lsgnR(반응 KC 마다 Δ = mean(w_교차) − mean(w_같은쪽)(E193 학습값)의 부호로 300/0)에서 E197 과 같은 판정의 네 칸 a_train ≥ 0.10 — 4/5 뇌. 부: lsgnA(Δ ≠ 0 인 KC 전부), 반응 KC 의 부호 일치율 sign(Δ) = sign(SXI) 보고.

## 예측
- **H119(학습 방향 충분)**: lsgnR 획득 ≥ 4/5 → 다음은 크기를 키우는 경쟁(정규화)형 갱신으로 학습(E199)
- **H119-null(학습 방향 부족)**: lsgnR 획득 칸 ≤ 1 이 4/5 이상 → 신용 할당 분기
- **부분**: lsgnR 2~3 칸이 4/5 이상
