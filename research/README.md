## 파일 역할
- **`CHARTER.md`** — 무엇을 연구하는가, 무엇이 성공인가, 무엇은 범위 밖인가
- **`current-state.md`** — **현재 믿음.** 역사 금지. 이 파일만 읽으면 연구 재개 가능해야 함
- **`invariants.md`** — 깨지면 안 되는 설정과 사실. 실험 전 필수 확인
- **`protocols.md`** — 측정 규약. 피 흘려 얻은 것만 적는다
- **`hypotheses/H###.md`** — 가설별 진술·예측·신뢰도·증거·판별실험
- **`experiments/E###.md`** — **실행 전** 사전등록, 실행 후 결과 추가
- **`mapped-regions.md`** — 탐색한 영역의 지도(실패 조건, 유효할 수 있는 조건, 재시도 조건)

## 실행 규칙
1. 실험은 `scripts/lab/run_experiment.sh E###` 로만 실행한다. 사전등록이 없거나 불완전하면 **거부된다**.
2. 사전등록에는 (a)검증할 가설 (b)조작이 실제로 듣는지 확인할 방법 (c)사전 판정 기준 (d)이 결과로 새로 알게 되는 것 — 넷 다 있어야 한다. (d)에 답할 수 없으면 **실험하지 않는다**.
3. 실험이 끝나면 결과를 사전등록 파일에 추가하고, **`current-state.md`와 해당 가설 파일을 갱신**한다.
4. `docs/research/DESIGN_RECOVERY.md`는 실행 로그(역사)로 계속 쓴다. 연구실 상태와 **분리**한다.

## 역사와의 관계
- `docs/research/DESIGN_RECOVERY.md` = 무엇을 했나 (append-only, 불변)
- `research/current-state.md` = 지금 무엇을 믿나 (덮어쓰기, 항상 최신)
둘을 섞지 않는다. 섞으면 이 세션의 실패가 재발한다.
