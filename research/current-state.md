## 4. 가장 중요한 열린 질문
1. **K38은 새 표본에서도 성립하는가?** 설정 탐색에 쓰지 않은 배선·난수열·평가 순서에서.
2. **그 학습은 유연한가?** 규칙 반전 재학습, 동결 후 유지.
3. **그 능력을 보존한 채 전체 모델로 옮길 수 있는가?** 입력 표현 → 행동 피드백 → 보상 전달 → 억제·반사를 하나씩.
4. (그 뒤) 두 고정 패턴을 넘어 **훈련하지 않은 사례에 공통 관계를 적용**하는가 — 개념 목표로 가는 전이 과제.

- 설정 탐색에 쓴 표본의 재현은 **회귀 검사**이지 독립 확증이 아니다.
- 코드를 고친 것과 검증한 것은 다르다. 수정 상태와 검증 상태를 따로 적는다.
