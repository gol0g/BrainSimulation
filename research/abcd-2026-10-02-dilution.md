## C. 다음 결정적 검증 — E138: 전체 모델 학습 효과의 상한은 어디서 오는가(분해 측정, 학습 런 없음)
**검증할 문장**: 전체 모델(반사 0)의 KC→motor 학습 효과가 작은 것(0.061~0.103, 판독 권한 R≈0.55 의 약 14%, 학습량을 늘려도 그대로 — K57·K58)의 출처를 둘로 가른다.
- **Q1 표현 상한 vs 학습 상한**: 좌/우 자극에 **발화 수 기준으로 선택적인** KC 만 이상적으로 교차 연결했을 때의 권한 R_sel 이 학습 효과와 비슷하면 → 표현(선택 KC 가 적음)이 상한이다. R_sel 이 학습 효과보다 훨씬 크면 → 학습이 선택 KC 의 몫을 다 쓰지 못한다(학습 동역학이 상한).
- **Q2 공통 모드 억제**: 비선택 KC(좌우 모두 발화)의 학습 가중치는 양쪽 motor 로 함께 오른다(E117). 그 KC 들만 초기값으로 되돌린 이식 평가에서 효과가 커지면 → 비선택 KC 의 공통 구동이 효과를 누른다.
**왜 이것인가**: 요청서 조건 4 — 통합은 입력 표현부터 분리해 어디서 능력을 잃는지 본다. 최소 회로에서 같은 학습 규칙의 실패 원인이 표현 희석이었다(K65). 다만 **자극이 둘(좌/우)뿐이면 좌우에 똑같이 반응하는 KC 는 변조폭에 원리적으로 기여하지 못한다** — 그래서 "희석"은 최소 회로(자극 8개, 공유 KC 가 오답 여유를 만듦)와 다른 방식으로만 작용할 수 있다: 선택 KC 가 적어 권한이 작거나(Q1), 비선택 KC 의 공동 상승이 motor 를 눌러 차이를 줄이는 것(Q2). E117 의 "공유 KC 1.7~2.9배"는 ≥1 스파이크 기준이라 지속 입력·잔여 발화로 부풀었을 수 있고(E121 에서 공통 입력을 꺼도 공유 수 128/124 → 127/115), 발화 수 기준으로 다시 잰다. **학습 런 없이** 저장 가중치(E119 반사 0, 뇌 10~14)와 이식 평가로 잴 수 있다.
**설계 초안**: 뇌 10~14, E119 반사 0 인자 그대로(BASE·ACT·`--reflex-w 0`), `--decomp-weights traces/E119/w_rw0_b*.npz`. 뇌마다 (1) **kcrate**: 같은 시드 새 뇌에 good=왼쪽/오른쪽 교대 제시(각 100회, E117 과 같은 3처리 스텝·사이 무자극 10스텝, 무자극 뒤쪽 5스텝으로 기준선) → KC 별 제시당 발화 수 → 선택 지수 SI = (e_L − e_R)/(e_L + e_R)(e = 기준선 뺀 유발) → 좌선택·우선택(|SI| ≥ 0.5)·비선택(활동하나 선택 아님)·무활동, 희석 지수(제시 구간 스파이크 중 비선택 몫), 학습 여유 분해(KC 별 Δg 합 × 발화). (2) 이식 평가 5종(각각 같은 시드 새 뇌, 한 번): none(초기) · all(학습 — E119 재현) · **kcpop**(모든 KC 집단 교차 300/0 — R 재현) · **kcsel**(선택 KC 만 선호 쪽 교차 300/0, 나머지 초기 150) · **kcselonly**(선택 KC 는 학습값, 나머지 초기).
**판정 초안**(사전 고정은 E138.md·criteria 파일에서): 뇌별 ρ = R_sel / |학습 효과|, κ = |kcselonly 효과| / |학습 효과|. Q1: ρ ≤ 2.5 가 4/5 이상이면 **표현 상한**, ρ ≥ 4 가 4/5 이상이면 **학습 상한**, 그 밖 보류. Q2: κ ≥ 1.5 가 4/5 이상이면 **공통 모드 억제**, κ ≤ 1.1 이 4/5 이상이면 억제 없음, 그 밖 보류.
